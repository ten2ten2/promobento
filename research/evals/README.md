# S1 评测输入

题目与使用范围以 [`topics.json`](topics.json) 为准。三家产品已有按 2026-10-23 官方页面整理的事实卡与素材来源：

- [DeepSeek](fact-cards/deepseek.json)：网页对话、API 平台与文档入口；主画面优先官网和无私人内容的初始界面。
- [MiniMax](fact-cards/minimax.json)：以 MiniMax Code 为软件题目，展示 agent 工作流和 Coding/Work 模式；不引用价格、速度排名或成本节省比例。
- [Duolingo](fact-cards/duolingo.json)：短课、读写听说与个性化练习；官方入门文章含可定位的产品界面截图。

这些是有来源、待确认的宣传输入。截图、Logo、录屏的本体尚未采集或上传；来源链接不等于可公开商用的许可。后续采集只使用已有的负责人内部评测决定，进入预发布 R2，不进 Git，不对外发布。每次真实评测前核对事实和权利记录，品牌页面发生变化时复核，不把旧价格或宣传数据沿用到新作品。

IELTS、JLPT、LeetCode 三张课程卡仍是虚构课程：课程时长、价格、学员结果、退款和讲师资料均不是网上可验证的真实业务事实，不能通过搜索补成“已证实”。它们可作为明确标注的虚构工程题目，真实宣传须替换为课程提供方的依据。代码回归另用 [`filmFixture`](../../packages/film-runtime/test/fixture.mjs) 和原创无字界面，不使用这些虚构业绩或第三方品牌素材。
