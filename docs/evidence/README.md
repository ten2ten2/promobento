# 验收证据规则

此目录只用于仍支持当前发布/能力声明的关键验收，不保存普通过程记账。当前没有可用于证明生产视频、邮件、付款或云端隔离已完成的报告。

普通语法、文档链接、JSON和参考测试结果放提交说明或CI，不为每次修改新建日记。真实Cloudflare隔离/回收、正常速度人工视听、模型/成本基准、邮件送达、支付退款和平台上传等难复现结果才需要独立记录。

记录注明当前commit、环境、镜像/资源/模型版本、实际命令、输入/输出hash、检查范围、失败和未运行项。占位样例/mock不标生产通过，短期URL/验证码/密钥/客户源码或素材全文不写入公开日志。私有原始证据用访问受控的引用，删除与保留跟随项目和合法审计要求。

报告失效且不再支持现行声明时移除引用和文件；许可证来源与仍需要的用户版本、订单/退款审计不属于失效文档。实施状态只由[进度](../implementation-status.md)维护，避免多处复制“已完成”列表。
