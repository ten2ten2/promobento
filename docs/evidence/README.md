## 后续应用证据

M0–M4 按 [测试与发布要求](../prd/06-testing-and-release.md) 添加真实记录，例如 Cloudflare 渲染、Waffo sandbox、权益并发、两类用户流程和平台上传。文件名包含日期与用途，提供素材或输出的合适标识，明确环境及测试范围。

不把私钥、访问令牌、带授权的下载地址、真实客户素材或完整付款个人信息提交到证据目录。可引用受控环境中的脱敏记录；需要审阅的可公开样片在取得素材授权后再纳入。
