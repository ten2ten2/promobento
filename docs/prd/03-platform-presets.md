# 平台预设与视频格式

v2.2 consistency-1。唯一数值来源为 `config/platform-presets.json`（本次不改变现有配置、版本或外部核查日期）。这些是产品交付规格，不是平台官方认证；平台账号资格、推荐、广告效果和内容审核不在导出保证内。

## 1 固定范围

仅15/30秒、默认30秒；30fps CFR、450/900帧。MP4/H.264 High/yuv420p/逐行/BT.709、faststart等编码参数由原配置解析；音源存在时AAC-LC 48kHz双声道，具体bitrate/GOP/file limit沿用配置。不能由用户、Agent或源码自报任意宽高/codec/fps。

| 平台 | 默认构图 | 允许额外选项 |
| --- | --- | --- |
| TikTok | portrait 1080×1920，9:16 | 无 |
| Instagram Feed | feed 1080×1350，4:5 | square 1080×1080，1:1 |
| Instagram Reels | portrait 1080×1920，9:16 | 无 |
| X | landscape 1920×1080，16:9 | 无 |
| YouTube | landscape 1920×1080，16:9 | 无 |
| YouTube Shorts | portrait 1080×1920，9:16 | 无 |

六平台共7个合法target，四种构图；使用 `presetId:aspectId`，不能因为square存在就接受TikTok方形。`presetId+aspectId+presetVersion+rulesVersion`必须一致。

## 2 Agent重新构图与冻结

草稿中Agent可自由重设镜头、文字、材质、相机和转场，同片不同目标可有不同衔接但总时长相同、事实一致。不强制四/六镜头，不以机械裁切代替适配；真实UI关键区域不能拉伸或丢失。

付款前完成该配置版本所有合法target的可执行源包/音轨/字体/封面及QA；允许共享经验证等价的source，但每个target必须有冻结映射。此时不必编码所有高清MP4。之后补平台只运行冻结分支，不能再调Agent创造新竖屏稿；用户修改另建新内容版本。流程、hash和错误按14，权益按05。

## 3 安全区、文字和封面

| 构图 | 产品保守安全区 |
| --- | --- |
| 9:16 | 上10%、右16%、下22%、左8% |
| 16:9 | 四边5% |
| 4:5/1:1 | 四边6% |

上述为产品谨慎设计值，不是永久平台像素规则。背景/装饰可越区，关键操作、报价和CTA不可被裁切。默认建议标题3行/CTA2行，可因明确设计调整但实际可读性必须通过。1080宽画面关键文字参考下限竖/方/Feed 36px、CTA32px；横32/28px。原UI微小字不是全部字幕，但关键操作需聚焦可读；对比度默认4.5:1。复杂字体/组合字符/RTL和混排按10检查，不按网站语言白名单限制。

封面从实际帧0..N-1选择，同构图JPG；可以调整标题但不得新增未确认事实。封面数据按target一起冻结。文件名如 `product_v003_tiktok_1080x1920.mp4`，服务端对象key只用内部ID和hash，不把未清洗产品名当路径。ZIP包含所选MP4/JPG/映射，重合文件内部可复用，下载包仍明确平台用途。

## 4 维护和验收

平台配置每条保留ID、版本、展示位置、手动上传路径、尺寸/编码引用、安全区、来源URL、核查日期、未核验字段及真实上传状态。外部API/广告规范不冒充普通手动上传限制；Instagram最终帖子类型和裁切按实际入口验证。未知字段保持未知，不猜值；运营月度或收到上传失败反馈时复核，本文不自动创建定时任务。

发布配置版本不可变，旧snapshot固定旧规则及可执行renderer；改新默认只影响新稿。安全兼容修复走有审计的免费correction，不覆盖原文件。相同视频、音轨、安全区和编码指纹可共享MP4，不仅按比例去重。

ffprobe验证所有成片：编码、像素、宽高、CFR、帧数、音轨、大小，文件时长容差≤2帧，音画结尾差≤100ms，无意外黑尾/空静音/旋转元数据问题。两类素材和15/30秒覆盖四构图、长文、数字/URL/CJK/RTL、缺字、横录屏与竖素材；复杂自由运镜同样验收。实际平台上传记录账号/入口/日期/hash/结果，审核或账号失败与编码失败分别归因。未真实上传不写“平台保证通过”。
