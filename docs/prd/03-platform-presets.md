# 平台预设与视频格式

尺寸、编码、安全区和响度目标以[平台配置](../../config/platform-presets.json)为准。实际上传与平台兼容性另行验收。

## 1 固定输出

视频仅 15/30 秒，默认 30 秒；30 fps CFR，450/900 帧。MP4、H.264 High、yuv420p、逐行、BT.709、faststart、码率、GOP 和最大文件大小按配置解析；音源存在时使用 AAC-LC、48 kHz、双声道。前端、Agent 和源码无权自报任意尺寸、编码或帧率。

| 平台 | 默认构图 | 额外允许选项 |
| --- | --- | --- |
| TikTok | portrait，1080×1920，9:16 | 无 |
| Instagram Feed | feed，1080×1350，4:5 | square，1080×1080，1:1 |
| Instagram Reels | portrait，1080×1920，9:16 | 无 |
| X | landscape，1920×1080，16:9 | 无 |
| YouTube | landscape，1920×1080，16:9 | 无 |
| YouTube Shorts | portrait，1080×1920，9:16 | 无 |

六个平台共有七个合法 `targetId=presetId:aspectId`、四种构图。必须验证平台与比例的组合，例如本产品不提供 TikTok 方形导出。已购作品使用快照固定的规则版本，版本缺失时按[14 目标与冻结](14-production-contracts.md#2-manifest目标与冻结准备)报错并免费修复，不能擅自换成新规则。

原生导出和任务身份见[渲染服务](../../apps/render-container/README.md)与[14](14-production-contracts.md#5-renderprotocol)，性能见[06](06-testing-and-release.md#渲染与导演性能目标)。

## 2 草稿重新构图与购买导出冻结

Agent 可按目标自由重设镜头、字幕、材质、相机、读字时间与转场，总时长相同、商业事实一致；不得拉伸或裁掉关键 UI。不限制镜头数和运动语言。

先用布局参数和安全区适配各目标，Q1 检查失败的镜头再交给 Agent 修复。购买并导出前必须准备并验证全部合法目标的来源，高清文件可以按需编码；付款后补平台只能运行已冻结来源。目标准备、快照和版本计量统一按[14](14-production-contracts.md#2-manifest目标与冻结准备)，购买创作额度与导出的区别见[05](05-waffo-billing.md)。

## 3 安全区、文字与封面

| 构图 | 产品保守安全区 |
| --- | --- |
| 9:16 | 上 10%、右 16%、下 22%、左 8% |
| 16:9 | 四边 5% |
| 4:5 / 1:1 | 四边 6% |

以上是产品设计值，平台规则变化时要重新核实。装饰可越区，关键操作、报价和 CTA 不得被遮挡。标题建议最多 3 行、CTA 最多 2 行；竖/方/Feed 关键字参考下限 36 px、CTA 32 px，横版分别 32/28 px。正文对比度目标 4.5:1，字体混排按 10 验收。静音时也应看懂卖点与 CTA；有旁白需可读上屏信息，逐词同步必须有真实转写证据。

封面选择真实帧 0..N-1，按目标输出 JPG，数据随来源冻结。需要不同封面标题时，该标题属于可审核的原生工程画面内容并先完成事实确认；不在导出后偷偷增加独立封面文案。修改实际封面选择属于内容变化。文件名如 `product_v003_tiktok_1080x1920.mp4`；存储键仅用安全内部 ID/hash。

客户正式交付须为每个所选目标登记MP4、JPG和映射说明，等价文件可共用同一物理R2对象；ZIP是附加派生物，不决定首次消费时点。此冻结/交付服务仍待实现，内部原生导出不代表客户购买交付已完成。

成片无需 PromoBento 品牌水印，与适用的 AI 标记、受众披露和第三方署名分别判断。按 09/14 对实际视频、封面及目标平台落实相应方案，不能仅在 ZIP 的映射说明中写“AI 生成”代替文件标记或必要披露。

## 4 配置维护与验收

每条配置保存 ID、版本、展示位置、手动上传路径、编码/尺寸引用、安全区、来源、核查日期、未知字段及真实上传状态。API/广告规范不冒充普通上传规则；运营按月或收到失败反馈复核，未核实字段不猜值。

版本继承、升级和免费修复统一按[14 版本管理](14-production-contracts.md#10-协议与发布版本)。共用物理文件仍须验证字节和授权，不能只比较宽高比。

节奏调整不能改变固定片长，配乐须在对应的 15/30 秒内收尾。音频编码、逐文件检查和测试样本见[06](06-testing-and-release.md)。真实平台上传记录入口、账号权限、日期、文件摘要和结果；未实际上传只称推荐格式。
