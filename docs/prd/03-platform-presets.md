# 平台预设与视频格式

唯一输出数值来源为 [平台配置](../../config/platform-presets.json)。产品预设不是平台官方认证；平台资格、审核与广告效果不由导出格式保证。配置来源日期与实际上传状态分别保存。

## 1 固定输出

视频仅 15/30 秒，默认 30 秒；30 fps CFR，450/900 帧。MP4、H.264 High、yuv420p、逐行、BT.709、faststart、码率、GOP 和最大文件大小按配置解析；音源存在时使用 AAC-LC、48 kHz、双声道。前端、Agent 和源码无权自报任意尺寸、编码或帧率。

| 平台 | 默认构图 | 额外允许选项 |
| --- | --- | --- |
| TikTok | portrait，1080×1920，9:16 | 无 |
| Instagram Feed | feed，1080×1350，4:5 | square，1080×1080，1:1 |
| Instagram Reels | portrait，1080×1920，9:16 | 无 |
| X | landscape，1920×1080，16:9 | 无 |
| YouTube | landscape，1920×1080，16:9 | 无 |
| YouTube Shorts | portrait，1080×1920，9:16 | 无 |

六平台共七个合法 `targetId=presetId:aspectId`，四种构图。必须验证配对及冻结的 presetVersion/rulesVersion，不因 square 存在就接受 TikTok 方形。执行已购快照必须解析该快照的规则版本，版本不可用则明确失败并进入免费的受控系统修复，不能套用最新配置拒绝或修改已购作品。

## 2 草稿重新构图与购买导出冻结

Agent 可按目标自由重设镜头、字幕、材质、相机、读字时间与转场，总时长相同、商业事实一致；不得拉伸或裁掉关键 UI。不限制镜头数和运动语言。

同一冻结创意优先使用构图参数、预设安全区及镜头语义布局（标题、焦点、UI、字幕、CTA）确定性派生各目标；仅当实际 Q1 证明镜头无法正确适配时，由 Agent 在购买并导出前修复该目标的独立来源。七个 target 仍各自验证，不把相同宽高比直接视为同一文件；`prepare_targets` 对用户不扣次数，但模型、CPU 和 QA 费用仍计入操作预算。购买并导出后不得调用 Agent 补画幅。

购买并导出前完成配置版本中全部合法目标的可执行来源、字体、资源、独立音轨、封面帧和预检报告。等价目标可共享来源，但每个目标都需明确映射和验证。无需提前编码所有高清 MP4。补平台只运行冻结分支，不再次调用 Agent；用户改变实际设计进入新内容，系统修复另有审计记录。先购买创作额度允许尚无素材或快照，仅授予权益；首次实际导出仍须完成同一全目标冻结门槛。具体版本和 hash 按 [14](14-production-contracts.md)，收费按 [05](05-waffo-billing.md)。

## 3 安全区、文字与封面

| 构图 | 产品保守安全区 |
| --- | --- |
| 9:16 | 上 10%、右 16%、下 22%、左 8% |
| 16:9 | 四边 5% |
| 4:5 / 1:1 | 四边 6% |

以上是内部谨慎设计值，不是永久平台像素规则。装饰可越区，关键操作、报价和 CTA 不得被遮挡/裁切。默认建议标题 3 行、CTA 2 行，可按设计调整但必须保持可读。竖/方/Feed 关键字参考下限 36 px、CTA 32 px；横版分别 32/28 px。截图原生微字不等于字幕，但关键操作须聚焦；正文对比度默认目标 4.5:1。复杂字体、混排、RTL 和组合字符按 10 验收。所有信息流目标应在静音播放时仍能理解核心卖点与 CTA；存在旁白时必须有对应的可读上屏信息/字幕，未取得准确转写时不得声称逐词同步。字幕也须通过目标安全区与实际帧检查。

封面选择真实帧 0..N-1，按目标输出 JPG，数据随来源冻结。需要不同封面标题时，该标题属于可审核的 Composition 画面内容并先完成事实确认；不在导出后偷偷增加独立封面文案。修改实际封面选择属于内容变化。文件名如 `product_v003_tiktok_1080x1920.mp4`；存储键仅用安全内部 ID/hash。

ZIP 包含所选目标的 MP4、JPG 和映射说明。当前导出契约为每个目标登记 video、cover、mapping 三种逻辑产物；等价文件可共用同一物理 R2 对象。ZIP 是附加派生物，不决定首次消费时点。

## 4 配置维护与验收

每条配置保存 ID、版本、展示位置、手动上传路径、编码/尺寸引用、安全区、来源、核查日期、未知字段及真实上传状态。API/广告规范不冒充普通上传规则；运营按月或收到失败反馈复核，未核实字段不猜值。本文不创建定时任务。

配置发布后不可变，新默认仅影响新稿。renderer/runtime 按可执行版本保留；安全修复创建有审计的独立更正版，不覆盖源包或已交付文件。只有实际来源、资源、音频、安全区、运行环境和编码相同才允许文件去重，不仅按比例比较。

时序参数编辑必须在既定 450/900 帧内重新分配镜头/停留；配乐不得因整小节对齐擅自延长片长，结束点应在对应的 15/30 秒边界内完成收尾。ffprobe 对每个文件检查编码、宽高、CFR、帧数、音轨、大小与旋转；视频严格 450/900 帧，容器时长容差 ≤2 帧，音画结尾差 ≤100 ms，无意外黑尾/静音。两类素材与 15/30 秒覆盖全部构图、长文、数字/URL/CJK/RTL、缺字与复杂运镜。真实上传记录账号权限、入口、日期、hash 和结果，审核/账号失败与编码失败分开；未实际上传只称推荐格式。
