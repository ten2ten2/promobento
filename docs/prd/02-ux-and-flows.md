# 界面与用户流程

本文用中文解释交互，所有自有生产页面的标题、按钮、提示、空态、错误、无障碍标签、政策与帮助内容首发采用英语。引号中的中文示意不是可直接放进生产界面的文案；核心英文资源种子见 `locales/en.json`，完整语言与主题规格见 10。

具体视觉、组件和响应式数值以 [11 UI 设计规范](11-ui-design-spec.md) 为准；本章继续定义任务步骤和业务交互。

## 1 页面与信息架构

| 路径 | 页面 | 核心内容与行动 |
| --- | --- | --- |
| `/` | 首页 | 两类场景并列、真实输入与样片、平台预设、价格、Create a video |
| `/use-cases/software-promo-video` | 软件产品用途页 | 发布与功能更新实例，进入时预选软件人群 |
| `/use-cases/course-promo-video` | 课程数字产品用途页 | 招生和上新实例，进入时预选内容团队人群 |
| `/examples` 与 `/examples/:slug` | 样片库与详情 | 输入、输出、分镜、时长、比例及许可说明 |
| `/formats` | 平台格式说明 | 六种预设比较、推荐值、适用路径与核查日期 |
| `/pricing` | 价格 | 项目包、追加包、预览、版本含义、保留期、税费说明 |
| `/create` | 创建入口 | 选择任务与平台；点击使用自己素材后登录 |
| `/app/projects` | 项目列表 | 草稿、导出中、可下载、即将到期、复制和删除 |
| `/app/projects/:id` | 编辑器 | 分镜、播放器、属性、平台预览、导出入口 |

| `/app/settings` | 设置 | Appearance 显示主题偏好，Use device setting 恢复跟随系统；工作区品牌、成员、邀请、订单、删除与支持 |

| `/admin` | 内部运营 | Cloudflare Access 与应用管理员双重鉴权 |

P0 不额外铺六套重复的平台营销页。用途页围绕任务，`/formats` 承载准确参数；后续有独立示例和稳定需求后再拆平台页。

## 2 首页与首次进入

首页首屏优先展示用户任务、真实输出和开始操作入口。品牌为 PromoBento，主文案为“Turn your product or course into a promo video.”，辅助文案为“Use your real screenshots, recordings, and assets. Edit your storyboard and export for your social channels.”，两类入口在同一视觉层级。

公开页导航和应用顶部使用单个太阳/月亮图标按钮，手机保持可访问且至少 44 px 的点击区域。默认跟随系统；当前有效主题为 Light 时显示月亮，动作和可访问名称为 Switch to dark mode；Dark 时显示太阳，动作为 Switch to light mode。点击后保存显式选择，刷新和再次访问恢复，之后系统变化不覆盖。Settings 的 Appearance 提供 Use device setting 恢复系统；公开页和只读审阅页的页脚提供同名动作，访客不用登录即可恢复。头部不显示三选菜单，也不采用三态点击循环。首发不展示网站语言切换器；用户文案不增加视频语言选择或识别确认步骤。具体首屏与保存规则见 10。

首屏下方提供可播放样片，每例显示输入了什么、视频多长、是否含用户上传配音、能导出哪些构图。价格与预览免费在开始按钮附近可见，不把支付方式藏到编辑完成后才揭示。

点击 Create a video 可先选任务、时长和平台。上传或生成之前 Google 登录；OAuth 返回后恢复刚才选择和获客来源。示例浏览不要求登录。登录失败不能丢失表单；显示重试和回到示例。

## 3 创建流程

### 第一步 选择任务

人群选择：Software product team 或 Course / digital product team。软件默认任务为 Launch 或 Feature update；内容团队默认任务为 Product launch 或 Enrollment。两组都可以选择全部共享模板。

时长默认 30 秒，另选 15 秒。平台多选，软件入口可预选 YouTube 与 X，内容团队入口可预选 Instagram Reels 与 TikTok；这只是可修改默认值，六个平台始终可见。

文案直接输入，可在同一场景或段落混用中文、英文及其他语言；不先选择一种视频语言。语言识别若用于排版，仅是辅助元数据，失败不阻止继续。浏览器语言与网站 UI 不改变用户原文，客户名称和上传素材保留原样，具体边界见 10。

### 第二步 上传素材

拖入截图或录屏，可上传 Logo。每个素材显示类型、尺寸、时长、上传与处理状态。录屏提供起止点与焦点选择；大段录屏只能选择实际用于场景的片段。

至少一个视觉素材就能继续。产品应指导用户补充第二个卖点素材，但不设置三张截图的硬性门槛。素材格式、文件大小和预算不足都在上传前后给出具体原因。上传中的项目自动保存，刷新后可继续未完成任务。

### 第三步 确认内容

填写产品名、目标受众、一句核心卖点、1–3 条补充卖点、CTA。课程入口额外突出“购买后得到什么”；软件入口突出“实际完成什么操作”。价格、日期、优惠与证明各有独立选填字段。

确认面板显示将进入视频的全部商业事实。用户逐项编辑，点击“这些信息已确认”后生成分镜；空字段不出现在分镜里。AI 不替客户勾选确认。CTA 链接明确是发布时可复制的地址，视频中的文字本身不能点击。

### 第四步 选择结构与样式

三种结构和两种样式用当前素材生成静态分镜预览，不使用无关演示品牌。用户可先选择系统推荐项，之后修改。

Clean / Bold 是成片的视觉样式。Appearance 控制网站界面，切换 Light / Dark 不重新选择视频样式，不反转素材，不重置播放器、焦点或未保存输入。

点击“生成分镜”前显示剩余 AI 次数。生成期间显示实际阶段：整理已确认信息、安排场景、验证内容。没有可靠进度时不展示伪造百分比。超时或失败提供“重试”和“手动填入模板”；人工填写同样能够付款导出。

### 第五步 编辑和预览

在编辑器播放自己的完整分镜与音频，切换平台检查；确认后进入“购买并导出”或“导出新版本”。当前版本还没有播放过时，导出面板提示检查预览，但不要求观看广告或重复等待。

## 4 编辑器设计

### 4.1 桌面布局

顶部显示项目名称、保存状态、协作者、撤销重做、剩余成片版本和导出按钮。左侧是按顺序排列的场景列表，中间是播放器与时间位置，右侧是当前选中场景的属性。播放器下方显示平台预设与安全区切换。

场景列表显示缩略图、场景类型、时长、标题以及错误或评论数量；支持拖拽重排和键盘上下移动。P0 采用场景列表加播放进度条，不提供任意轨道叠加的专业时间线。

右侧属性分为内容、素材、布局、声音。选中项目级对象时显示品牌、总时长、叙事结构和平台。所有字段有标签、可读错误信息及键盘操作，颜色不是唯一状态标识。

### 4.2 必须支持的局部操作

| 操作 | 行为 | 是否调用 AI |
| --- | --- | --- |
| 改标题、CTA、补充文字 | 立即更新对应场景 | 否 |
| 改价格、日期、数量 | 更新事实并要求重新确认，突出受影响场景 | 否 |
| 替换截图或录屏 | 保留场景内容，重新检查焦点与引用 | 否 |
| 调整裁切焦点 | 保存各比例的独立焦点，提供恢复自动布局 | 否 |
| 标注区域 | 最多 2 个矩形框，限定在素材范围内，可调整时段 | 否 |
| 改颜色和字体 | 选择受支持字体与颜色，检查对比度与溢出 | 否 |
| 调整场景顺序或时长 | 检查总时长与素材片段，更新预览 | 否 |
| 改写一个标题 | 显示改写范围与前后差异，用户接受后应用 | 是 |
| 重做整片分镜 | 生成候选草稿，保留旧稿，确认后切换 | 是 |
| 30 秒改成 15 秒 | 引导删减到 4 个场景；可手动处理或明确使用 AI 精简 | 可选 |

已确认的商业字段由单一事实对象管理。修改后受影响引用同步显示待确认，不允许一个场景仍显示旧价、另一个场景显示新价。自由文本中疑似新增的价格、日期或量化承诺也进入预检确认列表。

### 4.3 保存与冲突

表单停止输入约 1 秒后自动保存，显示 Saving、Saved、Offline draft 或 Conflict。保存携带 `baseRevision`；冲突返回 409，提供查看服务器新稿、保留本地草稿和逐项重新应用，禁止静默覆盖。

手动编辑支持当前会话的至少 20 步撤销与重做。服务端保留最近 20 个草稿检查点；所有已导出版本及其引用不可变，不受检查点清理影响。恢复旧版本创建新草稿，不修改旧的已付费输出。

### 4.4 音频和字幕

原始录屏默认静音。允许一条旁白与一条配乐，分别设置音量、起始位置和淡入淡出；可启用旁白存在期间的配乐降低音量。默认无配音、可无配乐。内置配乐只有在来源与再使用权限记录完成后才显示，否则提供上传入口。

旁白超出项目时长时阻止导出并提示裁剪或调整时长。P0 的字幕为人工输入的场景文字或旁白段落，不自动承诺逐词对齐；文字过多时提示缩短。预览必须能听到实际混音；浏览器自动播放限制下以明确的播放按钮开启声音。

## 5 平台选择与预检

六个平台选项显示对应画幅、时长和输出文件名。Instagram 信息流提供 4:5 默认与 1:1 选项；TikTok、Reels、Shorts 默认 9:16；X 与 YouTube 默认 16:9。切换平台既显示构图，也显示平台名称与推荐安全区。

错误分为阻止导出和建议两层。阻止项包括无效素材、文字或焦点越界、未确认事实、总时长不匹配、旁白超长、场景缺资源。建议项包括素材分辨率较低、画面中标题过多、当前官方规则需要复核。建议项说明原因，用户可确认继续；不能把未核验外部限制伪装成已通过的平台检查。

用户先看到自动重排，再可为横版、竖版、4:5、1:1 单独调焦点与文字位置。正文场景与事实共用，不复制四份互相脱节的业务文案。

## 6 购买与导出流程

首次购买面板固定当前内容与四种构图，展示项目名、缩略图、时长、所选平台、US$39、3 个成片版本、当前导出使用 1 个版本、保留日期规则和适用税费说明。

Waffo 收银台由服务端创建。返回站内后显示真实本地订单状态：确认中、付款已确认、付款未完成或会话过期。用户关闭收银台后可以从项目页继续付款，不能仅凭浏览器跳转显示付费成功。恢复的活动订单若关联旧快照，确认面板必须展示旧快照，并提供继续原订单或返回草稿的选择；不能用新稿封面套旧收银台。为新稿创建另一会话前须确认旧会话无法继续支付或已经安全过期并对账。

付款完成后自动导出购买时确认的版本。付款期间继续编辑产生新草稿，交付页提醒“正在导出已确认版本，新的修改已保存为草稿”。订单关联的画面不能随最新编辑变化。

已有额度时，按钮显示“导出新成片版本，使用 1 个，完成后剩余 N 个”。重复导出同一不可变版本则显示“继续生成所选平台文件”或“下载已有文件”，不重复扣额度。

额度耗尽时展示当前预览、历史文件和 US$12 追加包；仍允许在有效期内手动编辑和播放。追加包默认只增加额度，可另外勾选“购买后导出当前版本”，显示明确消耗。只有 Owner 可以购买，Editor 可发送站内申请或复制项目链接交给 Owner，不自动对其他人发送消息。

## 7 后台任务和交付

渲染阶段为排队、准备素材、生成画面、编码、校验、可下载。提供实际完成帧数或阶段状态，估计时间不足时显示“处理中”，不能用固定倒计时假装进度。

首次预留时冻结目标文件清单；其中的 MP4、封面和映射清单全部校验成功后，一次发布下载并确认消耗版本额度。并发新增平台不扩大该首批清单，在首次交付后继续生成且不再扣额度。部分文件失败时复用内部结果，仅重试失败项；未完整发布的中间产物不开放下载，最终失败释放预留额度。已交付版本补平台时原有文件持续可下载。ZIP 为随后生成的派生下载，可显示“正在准备”，失败免费重试，不改变首次交付状态。

交付页按平台显示 MP4、封面与复制说明，提供全部下载。后台工作不依赖页面保持打开；用户下次登录仍能找到任务和结果。文件在保留期内可重复下载，授权 URL 到期后重新生成，无须重新编码。

## 8 协作与分享

| 权限 | Owner | Editor | 未登录审阅者 |
| --- | --- | --- | --- |
| 编辑与 AI 操作 | 可以 | 可以 | 不可以 |
| 使用已购版本导出 | 可以 | 可以，须确认消耗 | 不可以 |
| 购买、订单和退款入口 | 可以 | 不可以 | 不可以 |
| 邀请与移除成员 | 可以 | 不可以 | 不可以 |
| 创建或撤销审阅链接 | 可以 | 可以 | 不可以 |
| 查看选定版本预览 | 可以 | 可以 | 有有效链接时可以 |
| 评论 | 可以 | 可以 | P0 不提供 |
| 删除工作区 | 可以 | 不可以 | 不可以 |

审阅链接使用高熵随机 token，默认 7 天失效；范围只包含选择的版本，且不能长于项目保留期。生成后说明“任何持有链接的人都可观看这份预览”，默认不开启原文件或高清成片下载。链接不能用于遍历其他项目；素材访问仍需服务端验证分享范围。

成员邀请由 Owner 复制加入链接，链接 48 小时有效、一次使用、可撤销。加入者先登录，消耗一个成员名额。Owner 转移和成员移除需确认；禁止移除最后一位 Owner。

## 9 移动端与可用性

P0 支持桌面与移动网页。桌面为完整编辑体验；手机以单列步骤、场景抽屉和属性底部面板实现同样的核心文字、素材、焦点、预览、付款与下载任务。大批量素材整理可提示使用桌面，但不能把手机到访直接挡在门外。

主要测试视口为 390×844、768×1024、1440×900。触控目标至少 44 CSS px；表单和播放器有可访问名称；弹窗正确管理焦点；支持系统减少动态效果偏好，编辑器 UI 动画减少不影响视频输出。

## 10 空态和异常

| 情况 | 用户可见处理 |
| --- | --- |
| 没有素材 | 提供上传提示和使用演示项目入口，演示与真实项目清楚区分 |
| 上传断开 | 保留已完成文件，可重传失败文件，不重新计入成功处理额度 |
| 不支持的编码 | 展示具体支持范围，不显示笼统的“网络错误” |
| AI 返回无效内容 | 不扣成功次数，可重试或手动填模板 |
| 字体缺字或文案过长 | 指明场景与字段，提供替换字体或缩短入口 |
| 录屏焦点在裁切外 | 高亮说明，修正后再导出 |
| 网络离线 | 本地草稿提示，恢复后解决版本冲突 |
| 支付确认延迟 | 保持订单查询，不要求用户立即再付一次 |
| 渲染失败 | 显示失败阶段和可恢复操作，不让用户为系统重试买单 |
| 项目过期 | 明确日期与只读状态；免费项目购买 $39 项目包恢复，已购项目购买 $12 追加包恢复 |
| 素材已清理 | 禁止付款假装可恢复文件；只能重新上传后创建可用项目 |

用户界面不显示容器 ID、队列、SDK、token 账单或内部堆栈。支持入口可以携带可复制的错误编号，方便定位问题。

## 11 语言与主题首发行为

首次访问默认 System。用户选择 Light 或 Dark 后，在同一浏览器的刷新、路由跳转、登录返回与再次访问中恢复偏好；选择 System 后继续跟随操作系统。主题偏好不写入项目内容和计费快照。

全站公共页面、登录前后界面、编辑器外壳、下拉菜单、弹窗、工单、只读审阅和内部后台均验收两种明暗表现。视频画布及客户素材保持其自身颜色；公开样片可以使用自己的成片样式。

SSR 首屏、Cookie、缓存、主题色彩、语言资源和具体测试以 10 为准。Waffo 收银台与 Google 登录页属于外部界面，只配置提供方真实支持的品牌、语言或外观设置；本产品不承诺替外部网站切换主题。
