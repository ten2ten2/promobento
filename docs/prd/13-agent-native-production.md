# AI 导演、自由创作与 Agent Studio

本章定义产品规格 v2.6 的创作方法；类型、采样、混音、QA 身份和计量由 [14](14-production-contracts.md) 的协议 2.6.0 定义，实施顺序见 [08](08-codex-execution.md)。这些规格不是运行中的服务或作品质量证明。

## 1 创作目标与技术自由

流程为理解真实产品 → 创意方向 → Treatment/节奏 → 原创动画代码 → 实际声音 → 真实帧/成片 QA → 定点修改。输出只允许 15/30 秒、30 fps 和 [03](03-platform-presets.md) 的合法平台目标；镜头数量、叙事、视觉风格、相机、过渡、图形语法和算法不设封闭枚举。

Agent 可编写 HTML/CSS/TS/JS、SVG、Canvas、WebGL、Three.js、Shader 或自己的动画算法，亦可复用获准组件。模板与运动语言是启发，不是能力上限。生产运行时 GSAP-free，画面由冻结输入和绝对时间决定；tween 起止值在准备阶段解析，相机采样计划位姿，仿真可预烘焙或从固定初态重放。具体接口见 [创作运行时合同](../../contracts/composition-runtime.d.ts)，整数帧与可信子帧采样见 14 §5。上游 GSAP 只用于许可隔离的本地基线，不进入在线依赖；WebGL 不可用时不能静默换成静态幻灯片。

创作始终受素材授权、真实商业事实、租户权限、依赖许可、资源预算和输出规格约束。网站主题和语言不进入创作身份；用户文案任意混排，翻译只能按明确指令作用于指定内容。客户确认不等于平台为商业主张真实性担保。

## 2 上游方法的适配

固定上游、逐文件采用方式与许可边界统一见 [09](09-sources-and-decisions.md#2-视频创作上游)。导演、运动语言、声音和诊断方法作为创作参考；多租户、支付、云作业、预算、资产代理与交付由本产品实现。云端 Studio 使用数据库和授权服务，不能以本地 JSONL 承担多租户状态。引入代码时保留来源、修改及真实测试，不把上游能力视为本产品已经实现。

## 3 导演工作流

**理解素材与目标。** 读取用户已确认事实、可用素材、受众、目标、品牌色与字体证据、声音方式、15/30秒和目标平台。公开输入范围由 [01](01-product-prd.md) 与 `config/input-capabilities.json` 决定；网址只为背景/CTA，CSV/无素材抽象动画仅内部研究。外部文本、素材中的指令均为不可信数据。

商业主张使用有来源的当前事实：价格、折扣、期限、名额、功能和数据按版本确认。不得编造评价、身份、使用体验、学员成绩、收益或稀缺性；真实评价保留原意和授权，个案不能直接推成典型结果。效果/收益说明适用条件，关联、激励或代言按 09 披露。证据和确认链按 14 §8 校验；缺依据时补充、删除或改写，不能由模型生成“证明”，也不能把用户勾选当平台认证。

**创意方向。** 提供 Fit/Amplify/Unexpected 三个实质不同的方向，分别包含一句话概念、镜头材料、运动语言、情绪、节奏、声音、素材依赖和风险。`run_result.directions` 在 `production.schema.json` 中可携带 language、look、palette、rhythm、sound、risk、whyItFits；BPM/色彩占比是可选信息，不制造没有证据的参数。关键帧必须由可执行工程真实渲染，不用提示词描述代替。用户已有明确方向或选“直接制作”可跳过三选一并执行明确路线；不能把方向卡额外包装成三次整片。方向与其素材处理、关键帧和QA归入同一操作及试用/已购项目的云成本预算，反复回看复用已有结果；所有方向生成须先登录，且该项目须有有效试用或已购处理权益。

**分镜与节奏说明（Treatment）。** 保存主信息、视觉语言、每段节奏/能量、阅读停留、关键声音落点、镜头目的和焦点连续性。机器结构通过 `run_result.treatment` 保存主信息、节奏段与连续性、真实关键帧引用；事件用半开整数帧区间 `[frameStart, frameEndExclusive)`，满足 `0 ≤ start < end ≤ totalFrames`；允许叠层/并行，也允许只有连续镜头。事件与音频计划的实际区间须由可信服务做跨字段语义验证。开场、主展示、最密和片尾的四帧来自实际工程，必要时增加边界附近帧。

“首3秒建立钩子”“节奏反差”“片尾品牌落点”是设计建议，不强制所有作品切镜、爆发或铺满节拍。安静字幕、极简长镜头与音乐主导片各按目标判断。最终产物要体现本产品事实和品牌，不是换一个名字仍完全相同的片子。

**先验证最难镜头。** 用实际字体、素材和目标分辨率检查风险最高一段，如 UI 环绕穿屏、复杂数据图表或跨设备连续构图。软件演示分开真实内容/滚动、设备外壳、取景包装、固定说明，先有业务事件再运镜，移动落定后留够阅读时间；动画包装不能伪装成产品原生功能。

## 4 自由工程与实际检查

源码、参数、依赖锁、资产、字体、乐谱/音效和 Treatment 都可追溯。除入口及参数合同外，工程目录由 Agent 决定，不强求固定场景数量或可解析 DOM。可编辑值固定存于源包 `values.json`，类型、范围、事实绑定及影响时序的声明独立于当前值；改值会产生新源包 hash。创作模块静态声明 editables、markers 和 regions，可全部为空，运行时不另提供一套动态声明。

`prepare` 解析固定输入，`draw(time)` 绘制完整状态，可信 adapter 负责桥接、取帧和资源屏障。宿主提供逻辑尺寸下的挂载根及按显式 `pixelScale` 分配的 canvas；作者不能用浏览器设备像素比另改布局或 buffer。视频先声明使用区间，按合同从 `videoFrames` 取对应 PTS 帧；字体声明引用平台字库及冻结资源，等待 `fonts.ready` 后绘制。界面与 Renderer 使用同一 [运行时合同](../../contracts/composition-runtime.d.ts)，挂载点、帧选择与字体来源均以该合同为准。

可信工具支持读取项目事实、检索参考、保存 Treatment、写文件/候选补丁、构建、渲染关键帧/片段、生成声音、QA、提出候选。Model Router 默认一主 Agent 驱动工具；复杂时按需委托子流程，不强制每阶段独立模型会话。写文件仅影响隔离候选，不能操作支付、管理密钥、其他工作区或已购源包。

模型配置由至少两种候选模型/设置在同素材、同预算的真实任务比较后确定；记录生成率、改稿成功率、主观盲审、时间、修复和每个可用结果的实际费用。不从单条样片宣称某模型最好。事实整理、意图分类、素材摘要可用经过验证的便宜模型；导演、源码和复杂改稿由质量达标的主模型承担，确定性检查不交给模型反复判断。`config/agent-policy.json` 中模型/价格/预算未标定时保持 disabled；修复和费用预留按 14 §6 执行。

方法包作为固定版本的缓存前缀，项目状态随后、本轮要求最后；实际命中按所用供应商、模型/价格版本、缓存期限测量，不复用别家平台或上游单会话的命中率。局部改稿只携带相关Treatment、镜头源码、邻接时段、素材引用与QA诊断；不能因精简上下文丢失已确认事实、依赖或影响范围。冷审、实际ASR及其缓存、音轨处理同样记入操作费用，不把免费或内部调用从台账排除。

## 5 音乐、音效和口播

Composer 让 Agent 根据 Treatment 编写 ABC 乐谱，由确定性合成器或许可审核后的采样演奏；快速路线采用获准的程序化音乐方向；用户也可上传授权配乐/录音。P0 音源按 09 的商用许可准入，实际使用的音乐/采样/声音须在 14 的资源清单与音频事件中绑定权利记录；程序合成或 ABC 乐谱不自动证明平台拥有全部版权。用户明确静音时无假音轨；即使有配乐/旁白，信息流目标也要在无声播放下看懂核心卖点和 CTA。缺真实乐器采样可用获准合成音色，不等于无声音。

画面/声音事件以整数帧提交，乐谱可用有理拍点或变拍，再映射到帧并记录舍入误差。需要同步的 marker 用 `audioEventIndex` 引用冻结的音频事件，可信层核验其帧号与事件起点一致。AudioPlan 的冻结参数、实际混音及预览/导出一致性按 14 §2 执行。beatMap、marks 与可选 voiceWords 分开，不制造未经测得的 ASR/词级对齐。

内部听感目标约 −16 LUFS、true peak≤−1 dBTP，不称平台统一标准。重要音效同步误差≤1视频帧，音画结束差≤100ms。音色、示范谱和声音授权须可追溯，SFX 参考种数不是效果白名单。

P0 支持无旁白、用户上传口播，以及用户明确启用的录屏原声；录屏默认静音。自动 TTS 和逐词对齐按输入配置的 P1 门槛开放，网站支持的语言不限制用户视频文案的语种。

真人口播或录屏原声包含商业主张时，须取得用户确认的转写稿，按片段映射 factIds；允许用户手填/修订，也可用已验证 ASR 辅助，不预设特定工具。未确认的语音商业主张不能凭 Agent 猜词冻结。为信息流目标制作读得懂的上屏文案/字幕，不声称不存在的逐词时间戳。超时长录音引导缩稿/剪辑，不能强行加速或延长成片。

只改无关文案/颜色不重做音轨；镜头时序影响节拍则变更对应audioHash并重新检查。频谱/响度只发现部分问题，不证明音乐好听；正常速度视听由真实用户或运营样本补足，不默认每单后台人工批准。

## 6 四层 QA

| 层 | 检查与结果 |
| --- | --- |
| Q0 源码/构建 | 语法、离线依赖、路径/授权/危险调用、时间与随机性，编译安全错误阻止执行 |
| Q1 实际帧 | 首/峰/密/尾、场景边界、真实素材、每个实际文字码位的字形覆盖/受控回退、遮挡、溢出、安全区、字幕与冷/顺/逆向seek |
| Q2 编码成片 | ffprobe、帧数/时长、闪帧、无意静止、异常切换、色彩/黑尾、音轨和同步；首次发布前必须通过 |
| Q3 人工/用户覆盖 | 产品辨识、故事、静音可读、字幕/转写、音乐和改稿落实；事实覆盖不足要具体复核，主观风格不伪装客观认证 |

付款前，服务端仅在全部目标源码、Q0/Q1 及必要片段/事实复核就绪时返回 `qualityEligibility=ready`；它是报告和当前授权的派生结果，不是创作 manifest 字段。报告及 REVIEW 豁免独立保存，快照冻结所采用的关联。新草稿无需 QA 即可保存，普通参数编辑和自动保存不启动检查。

不要求所有高清 MP4 提前编码；完整 Q2 绑定实际导出字节，在编码后、发布前执行。Q1 覆盖整片关键时点、镜头边界及高风险运动/字幕/CTA 片段，可用真实目标布局的可信低清预检降低费用。本地交互播放、静态方向图或付款页缩略图不能代替可信时序 QA。`BLOCK/REVIEW/INFO` 的处理按 14，不能用“导演认可”绕过安全、事实或编码错误。

单帧pop检查某帧与邻帧突变而左右相近；静止段结合计划阅读/停顿；硬切结合镜头表；运动曲线是节奏诊断，不以慢片为违规。上游低分辨率灰度启发式和阈值需要在纯色/高动效/停留/高密图表上标定误报，不把它当光敏或医疗安全认证。

QA 输入、报告与实际产物的绑定按 14 §8 执行。Canvas/Shader 文字无法提取时声明覆盖不足，交有权用户复核指定区间。Agent 自报的清单、截图或 pass 不能代替可信取帧与检查。

## 7 定点编辑和协作

点击时记录不可变 revision、合法 targetId、整数帧和相对坐标，以独立 `inspect` 消息请求 `hit-result`。DOM、Canvas 区域或 WebGL raycast 可提供声明中的 region/source map；不能命中时返回 null，仍可显式请求可信截图交给 Agent。跨域主站不能直接读取 iframe DOM，桥接只返回当前帧、当前会话的最小信息。

Agent先明确意图、影响文件/镜头/目标/声音与预算，在候选源包应用scoped patch，编译、抽样和未受影响范围回归。before/after交给用户，Accept用14的CAS改草稿，Reject保持原稿；候选交付与接受是两个生命周期节点，仅交付可用候选时计次，接受不再扣一次。只读分享不能发起Agent修改。

“第8秒推进改为环绕，其余不变”要真实改变源码并核查周边；全局风格变更先显示影响范围，不谎称局部。编辑失败或拒绝不能破坏当前确认内容；恢复包含源码、参数、依赖、声音和资产引用。可声明零个或多个 editables，按类型、范围、group、affectsTiming 和 factId 校验取值；没有可编辑项时明确选择 AI 修改。

时序变量只能在既定 450/900 帧内重新分配，无法确定性补偿时要求 AI 修改。事实绑定文字变化须重新确认原文；排版换行独立表达，不忽略零宽字符来绕过确认。本地编辑、回放和自动保存不启动 AI、可信 QA 或云端渲染；换素材的预处理/转写、可信预检和云端片段须明确发起，按项目权益和费用预算执行并复用有效缓存。

一组显式提交的批注按 14 共用基线、操作和一次候选计量，保留逐条定位；超限指出字段，不静默截断或拆成收费轮次。PatchResult 返回解读和影响摘要，界面解释修改范围。试用及付费权益只按 05，内部费用按 04/14 记录。

## 8 可控经验（P1）

工作区明确偏好由用户启用，可查看、修改、关闭和删除；单项目反馈只对当前项目应用。通用方法只来自有来源和使用依据的公共资料或独立工程总结，并保留适用范围与反证检查；不得将客户私有素材、提示、源码或反馈自动加入公开 prompt、训练库或其他工作区。数据处理边界按 04。已失效经验不再参与生成。排序为当前用户要求、当前确认事实、工作区明确偏好、已验证通用方法、上游启发；不跨租户混合。

验收用实际样片和失败反例，按 [06](06-testing-and-release.md) 记录创意差异、声音、精确帧、定点改稿、隔离、费用和人工介入。当前源码/文档参考不构成已运行这些能力。
