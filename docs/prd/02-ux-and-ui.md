# 界面、视觉与用户流程

适用于公开网站、登录、创建、Studio、交付、设置与后台。网站首发英语，客户视频可混用多种语言。公开页使用暖灰、可可色和少量品牌橙；Studio 的画布周围与时间轴使用中性灰，方便判断作品颜色。

## 1 职责、页面与来源

本章负责用户看到什么、如何操作。价格、次数、期限和授权见 [05](05-waffo-billing.md)，语言和主题见 [10](10-i18n-and-themes.md)，登录与权限见 [12](12-routing-and-auth.md)，制作方法见 [13](13-agent-native-production.md)，版本和任务规则见 [14](14-production-contracts.md)。

| 页面组 | 用户任务 |
| --- | --- |
| 公开网站 | 了解用途、查看真实样片、格式、价格、帮助与政策 |
| 创建与账号 | 设置任务、Google/邮箱登录、关联账号、确认邀请 |
| 工作区 | 管理项目、编辑、购买和下载；设置账号、外观、品牌与成员 |
| 受限入口 | 只读审阅指定版本；管理员使用运营后台 |

页面地址、入口权限和搜索索引规则统一见[路由配置](../../config/routes.json)。Help 复用公开帮助页；页面须返回正确 HTTP 状态。

## 2 视觉系统与基础组件

[UI tokens](../../config/ui-tokens.json) 维护字体、尺寸、间距、圆角和动效；[主题 tokens](../../config/theme-tokens.json) 维护颜色与对比度。组件读取这些配置，不能在页面另存一套数值。图标、分享图、字标和品牌口号的用法见[品牌素材](../../public/brand/README.md)。字标取 `typography.styles.wordmark`，四周至少留 `spacing.3`。

| 用途 | 字体与样式 |
| --- | --- |
| 公开页主标题、价格、字标 | Schibsted Grotesk 700；标题取 `hero` / `heroCompact` / `pageTitle` |
| 分区标题 | Geist Sans 600，`sectionTitle` |
| 正文、输入、按钮 | Geist Sans 400/500/600，`body` / `label` |
| 次要信息 | `small`；不能承载关键价格、错误或操作 |
| 帧号、时间码、时长、进度数字 | Geist Mono 400/500，使用等宽数字 |

Studio 内 display 字体最多用于项目名，其余使用正文或等宽字体。长项目名可截断，但须能查看全文。价格、日期、错误说明和操作不能因容器太窄被裁掉。

建站时按 `typography.fontSources.<role>.cssImports` 自托管所需 Latin 字重，使用 `font-display: swap`。CJK/RTL 保留系统字体回退，不依赖运行时字体 CDN。离线参考页未携带字体文件；生产字体和混排效果仍须在浏览器验收。网站字体与主题不能改变成片；缺字时调整作品字体或布局，不改写客户原文。

| 区域 | 配色与形状 |
| --- | --- |
| 页面和主要按钮 | 浅色为白底、暖灰表面、可可色按钮；深色为可可炭底、深暖灰表面、奶油色按钮。按钮用 `primary` / `primaryText` |
| 橙色点缀 | 用于播放头、当前帧、选中镜头、批注、免费标记和吉祥物，避免大面积铺色。`accent` 上用 `onAccent`；橙色文字用 `accentText`，必需图形用 `accentStrong` |
| 作品周围和时间轴 | `stage`、`timelineTrack`、`timelineTrackSelected` 使用中性灰。选中位置同时有边线、标记或文字，不能只靠颜色 |
| 边界与状态 | 输入边界用 `borderControl`，轻分隔用 `border`。错误、成功、警告须有文字或图标；危险实心按钮用 `dangerText` |
| 圆角与层次 | 控件和输入用 `radius.lg`，卡片和面板用 `radius.xl`，徽章用 `radius.full`；作品不加圆角。普通内容不加常驻阴影，菜单和对话框按指定阴影 |

画面批注钉使用 `accentStrong` 图标和 `surfaceRaised` 实底，外侧加明暗双描边，避免在任意视频底色上消失。普通文字至少 4.5:1，大字和必需控件/焦点至少 3:1；按实际背景及状态检查。选中文字用 `selectionText`，禁用原因仍须可读。

基础组件按 `ui.library` 和 [08 工具链](08-codex-execution.md#3-代码责任与可复现工具链)实施。按钮等待/禁用状态对应真实任务并保持尺寸；输入有外部标签和关联错误；Tabs/Select 支持键盘。纯图标按钮有可访问名称，装饰图标不重复播报。每个操作区域只突出一个主要行动。

平台预览切换与导出目标选择使用不同控件。镜头标记允许任意数量，也可以没有；排序提供拖拽之外的键盘操作。进度只显示真实阶段或已知帧数，未知时不编百分比或倒计时。错误、禁用原因和付费条件不能只放在悬浮提示或短暂通知里。

## 3 响应式、浮层与访问方式

尺寸与断点取 `layout`、`controls`、`breakpoints`。创建页宽屏为表单加摘要，手机单列；作品始终完整放入容器，不拉伸或裁切。

| 屏幕 | 公开网站 | Studio 目标布局 |
| --- | --- | --- |
| `xl` 及以上 | 双栏首屏，文案与样片错落排布 | 镜头栏、画布、属性栏 |
| `lg` 至小于 `xl` | 双栏首屏 | 可收起属性侧栏；比例选择在头部下方，镜头标记放入时间轴 |
| `md` 至小于 `lg` | 首屏上下排列，导航保持一行 | 同上，保留可收起属性侧栏 |
| 小于 `md` | 导航收进菜单，保留 Sign in；先展示标题、说明、两个用户入口和试用/价格，再展示样片 | 头部保留返回、项目名、撤销/重做；宽画面、可横滚时间轴，播放头在中线；底部切换 Properties / AI edit，固定当前主要行动 |

格式展示按七个合法目标的真实比例排布：宽屏分横版与竖版/Feed 两行；手机分横版、竖版、Feed 三行，每行等高。价格卡片窄屏纵向排列，免费试用保留一个主按钮。页边距使用 compact/medium/wide 配置。

手机底栏与桌面使用同一项服务端主要行动及禁用原因，按状态显示购买项目包、购买并导出、查看进度或下载等，不固定写 Buy & export。手机须能定位帧、输入、修改属性、撤销、付款和下载。

手机面板最高占用 `layout.mobilePanelMaxVh`，使用 dvh；软键盘和底栏不能挡住当前输入及正文。触控区域至少取 `controls.touchTargetMin`。文字放大后，头部和工具栏允许增高。

浮层顺序取 `zIndex`，对话框内菜单不能落到遮罩后面；关闭时恢复焦点，iOS 上实测滚动锁定。键盘须能完成创建到下载，支持 Skip to content、可见焦点、状态播报、Escape 关闭、200% 缩放和读屏。减少动态时取消界面位移，不改变作品时序。主题切换与恢复设备设置按 10。

## 4 首页、登录与设置

首页标题、说明和口号按[品牌素材](../../public/brand/README.md#文案分工)分工。软件与课程入口同级。CTA 旁说明样片试用、正式下载起价及项目包入口，金额和次数取服务端目录。样片标明来源和演示品牌，不使用虚构评价、客户标志或购买结果。搜索与 SSR 要求见 [07](07-growth-and-experiments.md)。

登录为单列，宽度取 `layout.formMaxWidth`，同时提供 Continue with Google 和邮箱验证码。邮箱使用 `autocomplete=email`，关闭自动首字母与拼写检查；不设置密码或找回密码页。验证码用一个文本输入框，设置 `inputmode=numeric` / `autocomplete=one-time-code`，支持整段粘贴和前导零；填满后仍由用户点击 Verify and continue。

服务器决定验证码期限、重发冷却和尝试次数。请求成功只表示已受理，不能提示邮件已送达；倒计时不逐秒读屏。错误保留输入和恢复入口。账号关联须验证双方并明确确认，同邮箱不自动合并；另建账号时说明原项目和订单不会带入。邀请登录后展示当前身份，由用户确认加入。

Account 展示已关联登录方式、添加 Google/邮箱、退出和关闭账号的申请入口；敏感操作按 12 重新验证。关闭账号可进入现有支持流程，身份核验和清理规则见 04。Brand/Members/Orders 按角色显示。项目列表展示真实缩略图、名称、状态和期限；空态引导创建，示例项目明确标为 Sample。

## 5 创建、素材与事实确认

流程为 Setup → Assets → Details → Creative direction → Studio，返回上一步时保留内容。软件入口可默认 YouTube/X，课程入口可默认 Reels/TikTok；所有既有平台均可选。时长默认 30 秒，可选 15 秒。不设固定风格白名单，也不要求选择视频语言。

上传、预处理、方向卡和生成前均须登录；登录前只保留任务选项，不承诺恢复尚未授权的本地文件。平台及 Feed 方形选择按 [12](12-routing-and-auth.md)保存和恢复，不能静默改回默认比例。

登录后可保存空草稿。Owner 明确领取试用，服务端返回资格和剩余次数；试用已用时，展示原试用项目或可购买的项目包。Editor 使用项目已有额度，需要购买时可复制链接给 Owner，不自动发送消息。试用与复制项目规则见 05，界面不自行判断是否免费。

上传展示大小、格式、实际进度、恢复入口和录屏裁剪范围。处理前收集本批素材的使用授权声明；新增或替换素材须重新关联声明。真人素材须有适用的肖像/声音授权。已知署名、期限、地域和渠道限制应提前展示，配乐提示可能遇到平台版权识别；用户勾选声明不能替代 [09](09-sources-and-licensing.md)的许可审核。

事实面板展示产品名、受众、卖点、报价/日期和 CTA，确认默认不勾选。网址仅作为背景或 CTA，不自动抓取。评价、成绩、收益、效果和限时主张按 13 展示依据；缺失时定位具体文字或声音片段，要求补充或修改，不能用一次总确认跳过问题。

生成前显示额度来源、剩余成功次数和正式下载需付费。需要探索时展示三个实质不同、可运行的方向；明确指令或直接生成不强制三选一。生成过程显示真实阶段，暂停、取消和恢复给出能执行的下一步，不出售目录之外的“付款继续”。

## 6 Studio、改稿与声音

Studio 包含保存、撤销、协作、版本余额、当前主要行动，以及镜头标记、画布、帧位置、目标预览、安全区和 Content / Media / Layout / Audio / AI Edit。允许任意镜头数或连续一镜到底；时间线使用整数帧，音画同步。

已声明的文字、颜色和布局可在本地不限次编辑，输入后立即预览，无须等自动保存。节奏、镜头时长等会影响时序的参数，首版统一通过 AI 改稿；界面说明原因。完整低清预览保留时长、全部内容和实际音轨；切换已准备目标不启动新任务。播放、缩放和隔离规则见[预览配置](../../config/preview.json)及 14。

普通编辑和自动保存不启动 AI、云端检查或渲染。上传处理、预检和云端片段各有入口，显示服务端返回的可用状态、用量和限制原因。云端片段尚未开放或用量不足时，保留本地回放；不能悄悄提交云任务。

预览显示 PromoBento 品牌水印，不能由作品代码关闭，也不能遮挡关键文字。正式付费下载去掉该水印；适用的 AI 标记和第三方署名保留。水印和检查的技术职责见 14，不承诺防止录屏。

用户可把相关批注合成一轮提交，每条保留目标、帧位置、坐标和文字。面板支持增删批注，显示条数/字符余额及“一次提交计 1 轮修改”；上限读取 [Agent 策略](../../config/agent-policy.json)，不另写死一组数值。时长或比例变化使位置失效时，要求重新定位，不自动移动批注。点选未命中对象时仍保存帧号和坐标；取帧与对象定位按 14。

AI 返回候选版本及改动摘要，用户比较前后再 Accept / Reject。接受前检查当前草稿是否已变化；冲突时保留两份结果供选择。拒绝保留原稿。全局改动先说明范围；未涉及声音时复用音轨，节奏变化后重新同步和检查。

输入停顿约 1 秒自动保存，Saving / Saved / Offline draft / Conflict 对应真实状态。保存失败或发生冲突时保留本地输入；较早返回的画面不能盖掉新输入。未保存内容不能用于购买或导出。修改后单独显示检查是否仍有效，不自动重跑；事实文字改动后须重新确认，并同步所有引用该事实的可编辑项。至少支持 20 步会话撤销/重做及 20 个草稿检查点；版本保存和恢复规则见 14。

录屏默认静音，用户启用后才使用原声。支持上传旁白/配乐、程序化作曲和音效，播放器播放实际混音；自动播放被拦截时显示播放按钮。音轨太长时引导裁剪或缩稿，不自动加速或延长影片。选择静音就不生成音轨。自动 TTS/逐词对齐属于 P1，通过输入能力验收后再开放；声音来源及转写确认见 13。

## 7 平台准备、购买与授权摘要

用户先审阅主目标的完整预览。选择 Buy & export 或 Export new version 后，才准备其余合法目标并检查；普通输入、保存和预览切换不触发这项工作。已有有效结果直接复用。只购买创作额度时不要求成片或导出快照。

准备结束后展示各目标的实际预览及必要改动，接受后冻结购买内容；期间草稿变更则先解决冲突。用户核对作品、价格和授权后才创建订单。付款期间的编辑另存为草稿，不改变这笔订单的交付内容。

质量状态由服务端返回。BLOCK 显示具体问题，须修复；REVIEW 显示待复核的规则和时段，由有权限的成员处理。内容变化后重新评估。检查通过不代表商业主张真实，也不保证目标平台批准广告。准备和编码后的检查分开显示，不能用静态缩略图代替动态验收。

主要行动、试用状态、剩余生成次数和改稿轮数都取项目响应；前端只呈现服务端允许的操作和限制原因，不根据订单自行计算余额：

| 服务端确认的状态 | 主要行动 | 界面说明 |
| --- | --- | --- |
| 空草稿、试用已用或复制项目无额度，符合购买资格 | Buy project pack | 先购买创作额度，不要求先有视频 |
| 主目标可用，其余目标尚待准备 | Buy & export / Export new version | 先准备并审阅各比例，确认后再付款或导出 |
| 当前内容已准备，符合单片购买资格 | Buy & export | 核对这份作品，可另选完整项目包 |
| 单片项目需要继续创作或交付新内容 | Upgrade project | 展示升级新增内容与差价 |
| 完整项目需要追加 | Add to project | 展示新增额度，默认不启动导出 |
| 有新内容及可用成片版本 | Export new version | 核对作品和首次导出目标 |
| 付款未完成、状态未知或退款处理中 | Continue payment / View payment or refund status | 继续查询原订单，避免重复购买 |
| 当前内容正在导出 | View export status | 展示原任务进度 |
| 当前内容已交付且仍可访问 | Download files / Add platform files | 继续下载或补格式，不再卖一次相同作品 |
| 同内容交付需恢复核查 | Request restoration review | 展示核查入口，完成前不再收费 |
| 退款结清后重新获得购买资格 | 对应购买入口 | 展示新的作品和额度，保留旧订单记录 |
| 非 Owner 需要购买 | Ask owner / Copy project link | 由用户自行联系 Owner |

购买核对展示封面、时长、首次目标、消费的成片版本、期限和税费。项目包/升级/追加默认只增加额度，用户可明确选择同时导出已确认作品。授权摘要、退款后果及完整条款统一来自 05；区分云端保存期限与成片使用权，不提示“退款收回全部版权”。

生成次数、AI 改稿轮数和成片版本分开显示，不统称 credits。免费预览提前说明下载需付费；不展示供应商成本或模型 token 账单。

## 8 交付、审阅与客户内容选择

交付页显示版本、期限和实际阶段。首次批次全部通过后一起发布；MP4/JPG/映射按目标提供，ZIP 的准备或失败独立显示。补格式时保留已有下载；关闭页面不取消已付款任务。期限和恢复见 05，删除与清理见 [04](04-architecture-and-data.md)；不出售无法恢复的交付，也不显示未实现的自动发布按钮。

按实际视频内容及目标平台提示所需 AI、合成内容或代言披露，并提供官方来源。一般动态图形不自动标为深度合成；发布前仍需审阅事实、人物及声音使用范围。标记要求见 09/13。

成员、购买和分享按 12 的权限显示。审阅页明确版本、截止时间和只读状态；分享给同事审阅不等于允许公开发布。

案例展示授权单独询问、默认不勾选，列明成片、渠道、用途和撤回方式，不包含原始素材或模型训练。拒绝不影响创建、付款或下载。撤回展示同意、删除项目和退款分别处理，数据记录按 04。

## 9 异常、应用验收与参考

| 情况 | 用户可执行处理 |
| --- | --- |
| 素材错误或上传中断 | 定位文件，恢复或重传失败项 |
| 权利或事实依据缺失 | 补充依据或替换具体素材/文案 |
| 生成失败且没有可用结果 | 保留原稿，按剩余预算重试或编辑已有内容，不扣成功次数 |
| 试用不可用或没有云操作额度 | 保存草稿，展示原试用项目或可购买的项目包 |
| 达到本轮预算上限 | 保存进度，说明可继续的动作，不缩短影片 |
| 缺字、混排或文字过长 | 定位字段并调整字体或布局 |
| 草稿被其他成员修改 | 保留候选，展示差异并让用户重新选择 |
| 浏览器能力不足 | 给出可用的兼容播放或可信预览方式，不用静态图冒充视频 |
| 支付未知或渲染失败 | 查询原订单并恢复任务，不诱导重复付款 |
| 项目过期、已删除或媒体被清理 | 展示实际期限和可恢复条件 |

错误说明使用普通语言和可复制编号，不暴露密钥或堆栈。验收视口为 390×844、768×1024、1440×900，覆盖明暗主题和 200% 缩放。
