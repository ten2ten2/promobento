# 界面、视觉与用户流程

适用于公开网站、登录、创建、Studio、交付、设置与后台。网站文案首发英语，客户视频原文可多语言混排。视觉采用杂志排版的层级和留白、冷中性表面与蓝灰操作色；作品始终是视觉中心。

## 1 职责、页面与来源

本章只定义呈现和交互。商品、价格、次数、使用期、退款及成片授权由 [05](05-waffo-billing.md) 定义；网站语言/主题由 [10](10-i18n-and-themes.md) 定义；身份、HTTP 与 URI 由 [12](12-routing-and-auth.md) 和 [路由配置](../../config/routes.json) 定义；制作方法与事实复核见 [13](13-agent-native-production.md)，版本、任务、预算与交付语义见 [14](14-production-contracts.md)。素材许可按 [09](09-sources-and-decisions.md)，展示同意、数据处理与删除按 [04](04-architecture-and-data.md)。界面不能另行推断服务权限。

| 页面组 | 信息与用户任务 |
| --- | --- |
| 公开网站 | 首页、软件/课程用途、真实样片、格式、价格、帮助与现行政策 |
| 创建与账号 | 任务设置、Google/邮箱登录、验证与关联、邀请确认 |
| 工作区 | 项目列表、Studio、交付、订单、Account/Appearance/Brand/Members |
| 受限入口 | 指定版本的只读审阅、经过管理员授权的后台 |

完整 URI、route ID、最低入口权限和索引策略只在路由配置维护。Help 复用公开帮助页，不另造重复设置页；页面必须返回真实 HTTP 状态，不以参考界面或通用 SPA 代替路由契约。

## 2 视觉系统与基础组件

[UI tokens](../../config/ui-tokens.json) 是字体、字号、尺寸、间距、层级和动效数值的唯一来源；[主题 tokens](../../config/theme-tokens.json) 是颜色与配对的唯一来源。品牌使用 PromoBento 文字字标，取 `typography.styles.wordmark`，四周至少保留 `spacing.3`。公开标题用 display 字体，正文、控件和编辑器用 sans；不在编辑器与数据中过度使用衬线或斜体。每个操作区域只有一个主要 CTA，两个人群入口同层级，视觉不能暗示未经证明的效果或收益。

| 用途 | token 与使用要求 |
| --- | --- |
| 首页主标题 | `typography.styles.hero`；小屏 `heroCompact`，display 字体 |
| 页面标题 | `typography.styles.pageTitle`，display 字体 |
| 分区标题 | `typography.styles.sectionTitle`，sans |
| 正文、输入 | `typography.styles.body`，sans |
| 标签、按钮 | `typography.styles.label`，sans |
| 次要元数据 | `typography.styles.small`；不用来承载关键价格、错误或操作 |

数字使用等宽数字，长项目名可截断但能访问全文。错误正文可换行且保留处理方法。图标取 `icons`，纯图标按钮有唯一可访问名称，装饰图标不重复读屏。

采用 React/TypeScript、React Router、Tailwind CSS variables、shadcn/ui Base UI、`@base-ui/react` 与静态导入的 Lucide；组件源码按需进入 `packages/ui`。不混用不同 primitives 示例，不让脚手架覆盖 Cloudflare/Vite 配置；SSR 不访问 window/document。实际依赖与 hydration 验证按 [08工具链](08-codex-execution.md#3-代码责任与可复现工具链)。

Light 使用白底/冷灰表面/深蓝灰操作色，Dark 使用炭灰/深灰表面/浅蓝灰操作色。选中文字使用 selectionText，必要输入边界用 borderControl，轻分隔用 border；错误/成功/警告同时有语义文字或图标，危险实心按钮使用 dangerText。普通内容无常驻投影，菜单/对话框取指定阴影，portal 继承主题。

普通文本目标 4.5:1、大字 3:1、必要控件与焦点 3:1，按真实背景验证。禁用原因仍可读；系统字体不保证跨设备字宽一致，客户原文不能因缺字被改写。视频字体和资源独立冻结，网站样式不能进入成片。

Button 的 loading/disabled 对应真实状态并保持尺寸；Input 有外部 label 和关联错误；Tabs/Select 可键盘操作。平台预览切换与导出选择使用不同控件。镜头列表支持任意数量或没有标记，并提供拖拽以外的键盘移动。进度只显示真实阶段/帧数，未知时不用固定倒计时；状态、错误与付费条件不能只藏在 tooltip 或 toast。

## 3 响应式、浮层与访问方式

间距、边距、公开/创建/表单/正文宽度、导航与控件尺寸分别取 `spacing`、`layout`、`controls`。公开首页采用文案/作品非对称双栏，窄屏上下排列；创建页宽屏为主表单加摘要，手机单列。作品内容不强制裁成圆角，画布使用 contain，不能因容器拉伸或裁切作品。

Studio 在 `breakpoints.xl` 及以上采用镜头标记栏、弹性画布、属性栏；`md` 至 `xl` 之间用属性侧面板；小于 `md` 用预览/时间加底部属性与 AI 面板。手机保留帧定位、输入、属性、撤销、付款和下载，不缩小整套桌面界面或退化为只读。各栏、头部和工具条尺寸取 `layout`，文字放大后可自然增高。

手机面板取 `layout.mobilePanelMaxVh` 并使用 dvh；普通与购买核对对话框分别取 dialogMaxWidth/reviewDialogMaxWidth。软键盘和底栏必须为当前字段及正文保留安全空间。所有触控区域至少取 `controls.touchTargetMin`，紧凑桌面控件不缩小触摸命中区。

浮层按 base、sticky、dropdown、sheet、dialog、toast、tooltip 的 `zIndex` 顺序。对话框内菜单属于其浮层上下文，不能落到遮罩下；关闭按栈恢复焦点，背景滚动锁定须在 iOS 实测。状态/面板动画取 `motion`，减少动态时取消 UI 位移，不改变视频时序。

键盘须能完成创建、编辑、核对付款和下载；Skip to content、可见焦点、live region、Escape/关闭恢复焦点均可用。支持 200% 缩放、读屏和混排文字。主题按钮、Use device setting、Cookie/SSR/缓存行为统一按 10；Settings 及公开/审阅页脚均可恢复设备设置。

## 4 首页、登录与设置

首页主文案为 “Turn your product or course into a promo video.”，辅助为 “Use your real assets. Direct the motion, refine any frame, and export for your channels.”。软件与课程入口同级。CTA 旁显示一次样片试用、正式下载起价及继续创作的项目包入口，金额和可用次数取服务端目录，不在 UI 维护另一套价格。手机首屏主标题、创建按钮与付费边界可读，作品自然向下延伸。样片来源和演示品牌明确，无虚构评价、客户 Logo 或购买结果；SSR 与搜索要求见 07。

登录使用约 480px 单列，包含 Continue with Google 和 Email address / Send sign-in code。邮箱 autocomplete=email，关闭自动首字母与拼写；不提供密码或找回密码页。验证码用单个 text/inputmode=numeric/autocomplete=one-time-code 输入，支持整段粘贴和前导零；填满后仍须明确 Verify and continue。

期限、冷却和尝试次数来自服务器与 auth 配置，不维护独立计时规则。请求被接受不等于邮件送达；重发倒计时不逐秒读屏。错误持续展示并保留合法创建选项和输入。关联页仅在有效 proof 下展示目标资料，要求双方验证和明确确认；同邮箱不自动合并。独立创建账号须说明项目和订单不带入；邀请登录后仍显示当前身份并由用户明确 Join workspace。

Account 只展示实际关联的登录方式、添加 Google/邮箱、当前/全部退出；不显示未实现的解绑、密码或 MFA。敏感动作按 12 重新验证。Brand/Members/Orders 按角色展示，项目列表用真实缩略图、名称、状态、时间/期限与菜单，空态引导创建或明确标注 Sample，不填假用户数据。

## 5 创建、素材与事实确认

流程为 Setup → Assets → Details → Creative direction → Studio，可返回修改并保留状态。软件入口可默认 YouTube/X，课程入口可默认 Reels/TikTok，全部配置内平台可选。时长默认 30 秒，可选 15 秒；Feed 方形仅是该平台合法选项。无固定风格白名单、无视频语言步骤。

素材上传、预处理、方向卡和生成前均须 Google 或邮箱登录。登录前只保留低成本任务选项；文件授权不保证跨登录跳转有效，不能承诺恢复浏览器未授权文件。公开 `returnTo` 的 `platforms` 字段只放 12 允许的平台 ID；用户明确选择的 `targetIds` 及 Feed 方形保存在服务端 flow/草稿上下文并重新校验，恢复时不静默改回默认构图。

登录后可先保存空 draft。Owner 明确领取试用时提交 `requestTrial=true`，其他情况默认 false；服务端返回的资格和剩余次数决定下一步。不可用或并发已领取时显示有权限的原试用项目或先购项目包入口，不要求空稿先有素材/快照；不能偷偷消费其他成员资格。Editor 只使用项目已有额度，需购买时复制项目链接给 Owner，不自动外发消息。试用、复制项目、云操作和恢复购买资格统一按 05，UI 不因看到复制素材或相同哈希自行宣告可免费处理或单片导出。

上传展示实际大小、编码、处理进度、恢复入口及录屏起止/焦点；至少一份合法视觉素材才能生成。开始处理前取得用户对本批素材的权利声明：自有或已获适用于处理、预览及预定发布用途的授权，含真人素材时已取得该用途所需的肖像/声音授权。新增或替换素材重新关联声明；用户的授权材料和平台许可审核按 09 分别记录。存在署名、期限、地域、客户或渠道限制时在使用前提示；配乐提示目标平台可能进行版权识别，不把勾选声明展示为平台保证不侵权或必然通过识别。

事实面板展示产品名、受众、卖点、可选报价/日期与 CTA；确认默认未选，模型不能代勾。网址只作为背景/CTA，不自动抓取。评价、推荐、学员成绩与收益/效果/紧迫感主张按 13 显示来源、引用和待核查项；缺依据时定位具体文字或声音片段，要求修订或补充，而不让用户用一次总确认绕过明确缺失项。

点击生成前显示额度来源、剩余成功次数及正式导出需付费。Director 按需展示三个实质不同方向的真实可运行关键帧；明确指令或直接生成不强制三选一。方向刷新受同一操作及系统预算约束。阶段可显示排队、理解、方向、难镜头、代码、音频、实际帧检查和候选可用；有真实数据才显示百分比。等待用户、取消、预算暂停和恢复按 14，不提供目录之外的“付款继续”入口。

## 6 Studio、改稿与声音

顶栏包含保存、撤销、协作、成片版本余额和当前主要行动。镜头标记栏、画布、时间位置、目标预览、安全区以及 Content / Media / Layout / Audio / AI Edit 组成编辑器，允许任意镜头数或连续一镜到底。时间线使用整数帧，音画共用时钟。已声明变量可本地不限次编辑和回放，普通编辑与自动保存不启动 AI、可信 QA 或云端渲染；新上传、预检和云端片段分别展示可用状态及触发动作。

完整样片在独立 origin 的浏览器宿主中播放，保留所选 15/30 秒、全部内容和实际音轨。平台逻辑宽高不变，宿主按 [预览配置](../../config/preview.json) 的 `pixelScale` 降低绘制像素，统一 DOM、Canvas 和 WebGL 的挂载与缩放。播放、暂停、拖动和切换已准备目标只使用已授权资源，不隐式开启云端片段任务；浏览器结果不是可信 QA 证据。

预览的 PromoBento 品牌水印由宿主合成，不能由作品源码关闭；可信截图或片段由可信层合成相同水印。Q1 检查无品牌水印的作品帧，另验水印不挡关键文案和 CTA。品牌水印、必要 AI 标记及第三方署名分别处理，付费去品牌水印不删除后两者。这是预览与正式交付的产品边界，不承诺阻止录屏或充当 DRM。

每轮改稿在同一个 base revision 上提交 1–5 条 `comments`，合计最多 4,000 个 Unicode 码点，可跨相关镜头。每条保留自己的 targetId、帧号、归一化坐标和文字。面板可增删待提交批注，显示数量/字符余额和“一次提交计 1 轮修改”；服务端超限时定位需要缩短的内容，不按每条评论扣次。时长或目标变化使位置失效时须明确重新定位，不能自动移到另一帧。数量和长度实际取当前策略，不展示 token 或后台模型账单。

点选通过独立 `inspect` 命令返回当前帧的 `hit-result`，只引用可信静态声明中的区域及源码位置；无法命中时仍保留帧号和坐标。审片截图由可信渲染服务重新取帧，不把客户端或不可信源码上传的图当证明。主站不读取跨域 iframe DOM，受限 bridge 只返回最小信息。

Agent 改稿产出不可变候选和影响摘要，用户比较 before/after 后 Accept/Reject；Accept 按当前权限与 base 执行 CAS，Reject 保留当前稿。全局变化先说明范围，不承诺无关片段绝对不变。颜色或文字未涉及声音时复用音轨；节奏变化重新同步和验片。保留当前时间、讨论上下文及完整源码/音频恢复能力，过时请求给出冲突与重新应用选择。

输入停顿约 1 秒自动保存，Saving / Saved / Offline draft / Conflict 必须对应真实状态；携带 baseRevision，不静默覆盖。草稿只保存创作内容，无须先取得 QA 报告。保存后单独显示检查状态；内容改变使受影响的准备资格失效，但不自动重跑检查。价格、日期和 CTA 等事实绑定文字改动后标出待确认项，普通保存不能代用户确认。至少 20 步会话撤销/重做及 20 个草稿检查点；不能裁掉已购版本、活动候选或在途任务引用。恢复同内容创建新 revision，交付仍按 14 的内容身份计量。

录屏默认静音，显式启用才纳入原声。支持上传旁白/配乐、程序化作曲与多个 SFX，播放器使用实际混音；自动播放受限时提供播放按钮。音轨过长引导裁剪或缩稿，不自动加速或延长影片。显式静音不生成假空音轨；采样不可用可用获授权合成器。自动 TTS/逐词对齐属于 P1，通过输入能力验收后才开放。商业语音转写确认和声音来源按 13，不预设某个 ASR 已部署。

## 7 平台准备、购买与授权摘要

Studio 先提供主目标的低清、完整真实预览，保留所选 15/30 秒时长、实际音轨或显式静音。用户明确进入 Buy & export，或用已有版本额度选择 Export new version，才触发 `prepare_targets`：在当前权限和预算内准备全部合法目标的布局、真实预览、必需 QA 及可执行来源。文字输入、自动保存、普通变量编辑和切换预览本身不启动有成本的全目标准备；已有且仍有效的准备结果直接复用。Prepare platform layouts 是此流程中的准备阶段，不要求用户在审阅主片前先完成它。

新准备结果形成不可变候选，展示必要的布局/音轨变化，经当前 base 的 CAS 接受后才冻结全目标快照；若与期间改稿冲突，保留两份结果并要求选择，不自动合并。随后展示快照和购买摘要，用户确认后才创建 checkout；付款后按快照编码首次所选目标。`top_up_only` 直接购买创作权益，不进入这条准备流程；宽限期只使用已有有效快照，恢复条件按 05。

目标缩略图只用于切换预览，不能以静态图代替动态 QA。切换后可播放实际时间段并检查安全区。预览明确标注 Preview / Paid download；Q0/Q1 来源准备与 Q2 编码后检查分别呈现。服务端根据当前内容、报告和复核记录返回 `qualityEligibility`，前端不从 manifest 推测是否可购买。BLOCK 定位具体问题且不可豁免；REVIEW 显示规则和时段，当前有权成员的处理另存记录，不改写检查报告，内容变化后重新评估。预检不构成商业真实性或目标平台广告审核保证。

下表定义界面行动。项目响应的 `availableActions` 给出可用操作及限制原因，价格、次数和资格以 05 及可信服务为准；UI 不自行推导订单/退款依赖或重建 grant：

| 服务端确认的状态 | 主要行动 | 必须呈现的边界 |
| --- | --- | --- |
| 空 draft、无权益复制项目或需要开始创作，符合项目包资格 | Buy project pack | 先购创作，不要求不存在的快照，不自动渲染 |
| 主目标可用、当前允许云操作，但导出来源尚未全目标准备 | Buy & export / Export new version | 先进入平台准备；就绪并确认快照后才创建 checkout 或导出任务 |
| 当前稿已准备且符合初始单片购买资格 | Buy & export | 显示当前确认内容；可另选完整项目包，分别展示实际权益 |
| 有效单片项目需要继续创作或新内容交付 | Upgrade project | 展示已有记录和新增差额；默认仅增权益 |
| 完整项目需追加且符合资格 | Add to project | 展示本次新增权益；默认仅增权益 |
| 新内容且有可用成片版本 | Export new version | 确认作品与首次目标，成功交付消费版本 |
| 活动/未知付款或未结算退款 | Continue payment / View payment or refund status | 展示原订单内容与实际结算状态，不诱导重复付款 |
| 同内容已预留或执行 | View export status | 使用原任务状态，不重复开任务或扣次 |
| 同内容已交付且交付权限有效 | Download files / Add platform files | 按当前权限、来源与生命周期展示；余额为零也不重复购买 |
| 服务端要求同内容交付恢复核查 | Request restoration review | 先完成 05 规定的人工恢复，不直接新收款或复用撤销收据 |
| 退款结清后服务端重新确认购买资格 | 相应购买或升级入口 | 展示新的确认内容和当前权益；不能在前端抹掉旧记录 |
| 非 Owner 需要购买 | Ask owner / Copy project link | 不自动发邮件或消息 |

购买核对显示冻结内容、封面、时长、首次所选目标、本次消费的成片版本及期限/税费；全目标缺项时定位待准备内容。项目包/升级/追加默认只增权益，用户可明确选择已确认快照同时导出。继续已有订单时展示其原快照；付款期间的编辑另存草稿，交付仍读取订单快照。

核对付款面板给出 05 的授权摘要并链接完整条款：预览仅供评估及受控审阅，付费成片在约定范围内可长期商用、无需署名 PromoBento；平台通用元素不独占，第三方与客户自带素材条件仍适用，不保证版权登记或广告获批。明确区分云端保存期限与成片使用权。退款界面显示受影响订单、权益和具体授权后果，不笼统提示“退款将收回全部版权”；适用消费者权利与例外按 05 处理。

创作成功次数、AI 改稿轮数和成片版本分开显示，不统称 credits。免费样片注明正式下载付费；单片不展示追加包捷径或赠送 AI 次数。次数与操作状态按 05/14 的服务响应呈现，用户看到可继续的动作及限制原因，不展示供应商成本账单。

## 8 交付、审阅与客户内容选择

交付页展示实际版本、期限和阶段，按 14 显示首次批次准备/发布状态。初批失败不提供零散 ready 文件；正式发布后按目标提供 MP4/JPG/映射，ZIP 准备或失败独立显示。补目标保持已有文件可下，重下不重新编码；关页不取消已付款任务。服务期限、宽限和恢复选项来自 05，数据清理状态来自 04，不出售不可恢复交付，不提供未实现的自动 Publish。

导出时按目标平台和内容类型给出必要的 AI/合成内容、代言关联等披露提示及当前官方来源；只在适用时要求用户采取动作，不把一般动态图形一概标成深度合成。平台规定与可实现的机器可读标记按 09/13 核验，不能宣称写入普通元数据就自动通过法规或平台审核。用户发布前仍须审阅事实、人物和声音使用范围。

Owner 管理成员、购买、退款和工作区删除；Owner/Editor 可在权限内编辑、运行 AI、消耗已有版本与管理分享。邀请与审阅按 12，界面展示实际截止及可撤销状态。匿名审阅者仅查看指定版本，不评论、不执行 Agent 或访问源码；受控评估分享不授予公开发布或投放权。

案例展示授权是独立、默认未选的选择，不与服务条款、付款或素材权利声明合并。用户看到具体选定的已交付成片、展示渠道、用途和撤回方式；授权不包含原始素材或模型训练。拒绝不影响创建、付款或下载，分享给同事审阅也不代表允许 PromoBento 公开宣传。当前同意状态和变更结果按 04 记录；撤回展示同意、删除项目和申请退款分别说明，不把任何一个动作当成其他动作的隐式确认。

## 9 异常、应用验收与参考

| 情况 | 用户可执行处理 |
| --- | --- |
| 素材错误或上传中断 | 定位格式/文件，恢复或重传失败项；不重复扣已成功处理的额度 |
| 权利或事实依据缺失 | 定位素材/主张，补充依据或替换；不让付款绕过 BLOCK |
| 无可用候选的生成失败 | 保留原稿，按剩余预算恢复或编辑已有参数；不扣成功次数 |
| 试用不可用或云操作无权益 | 保存空 draft，显示有权限的试用项目或符合资格的先购创作入口 |
| 本轮预算上限 | 保存检查点并说明可继续范围，不截短影片或出售不存在的续跑商品 |
| 混排、缺字或过长 | 定位字段，调整字体或布局，不禁整种语言 |
| 旧 base 或成员竞态 | 显示 409 冲突，保留候选并明确重新应用，不静默覆盖 |
| 浏览器能力不足 | 给出兼容实现或可信预览方案，须用户确认，不用静态图冒充完整动画 |
| 支付未知或渲染失败 | 保留订单查询和恢复，不诱导重复付款 |
| 项目过期、主动删除或媒体清理 | 展示服务端实际期限、权限和可恢复条件；具体购买/数据边界按 05/04 |

普通用户只见安全解释和可复制错误编号，不展示密钥、堆栈或 token 账单。验收视口为 390×844、768×1024、1440×900；关键操作不能因主题、缩放或手机输入丢失。
