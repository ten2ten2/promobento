# GPT 获客、作品质量与付费实验

两类首发用户同时验证完整自助价值。GPT 是流量来源，不是独立商业模式；页面可访问、机器人检索、站长自测、陌生推荐、素材激活和付款分别计量。

## 1 入口与公开内容

软件页说明截图/录屏如何变成可改稿的 15/30 秒短片；课程数字产品页展示封面/目录/节选、真实交付物和 CTA。每页包含授权样片、输入限制、目标规格、可修改范围、价格、保存期和开始操作。未开放的 URL 抓取、CSV、TTS 和排期不宣传可用。

网站英语首发，视频原文允许混排。公开 SSR、真实 poster/MP4、文字说明、FAQ、准确结构化数据，不编造评分或背书。canonical/sitemap 只覆盖真实发布页面，主题/UTM 不产生新索引 URL，不建空语言页面。搜索与训练爬虫策略分开配置，按 [官方爬虫说明](https://developers.openai.com/api/docs/bots) 在实施时核实；放行不保证推荐，私有项目、token 和账务不能暴露。

## 2 事件和来源

事件保存 eventId、UTC、environment、适用 user/workspace/project、独立分析 session、audience、来源、duration、targetIds、操作和政策版本。不用登录 Cookie/hash 作分析标识，不收集 OTP、token、原始回跳 query、客户全文、私有 URL、源码或支付敏感数据。文字语言和 styleLabel 可选，不是准入。

首触、最近非直接来源、自报来源分开；可信 referrer/UTM 与客户自报分别标注，direct 不自动归 GPT。付款来源从订单已保存关系恢复。内部、赠送、自测、测试支付和关联人员可过滤，保留可核对的原始统计。

| 事件 | 定义与权威来源 |
| --- | --- |
| landing_viewed | 合格人类用途页会话，去重并排除机器人 |
| signup_completed / login_completed / auth_method_linked | 真实账号、会话和身份关联成功，不重复算注册 |
| project_created / assets_ready / facts_confirmed | 成功写入、合法视觉素材、当前事实用户确认 |
| direction_candidates_ready / creative_direction_selected | 真实方向帧可访问及选择，尚不算整片成功 |
| candidate_ready | 主目标完整可用候选交付，与一次整片成功消费同一业务事件 |
| patch_ready / patch_accepted / patch_rejected | 候选交付和用户接受/拒绝分开；接受不再扣次 |
| target_preparation_ready | 全合法目标来源/音轨/报告就绪，不是新付费版本 |
| own_preview_played / own_preview_completed | 当前 revision 实播 ≥3 秒/累计 ≥90%，客户端信号不充当质量证据 |
| checkout_started / payment_confirmed | 本地 checkout 建立/权威付款入账；财务事件不采样 |
| export_release_ready / download_started | 首批发布消费/文件传输；下载不等于公开发布 |
| refund_succeeded / extra_pack_paid | 真实退款/追加，和新项目复购分开 |
| published_self_reported / usable_video_confirmed | 用户反馈，不伪装为平台遥测 |

## 3 指标口径

素材激活率按合格工作区与合法素材统计；个人预览按实际播放/素材就绪工作区；预览到付费按首次真实付款工作区/合格个人预览工作区。交付完成率按唯一 release 去重，首次成功与重试后成功、人工介入分别报。新 snapshot 对同 contentHash 的重复请求不扩大分母或收入。

首次价值时间从 assets_ready 到 own_preview_played，计算阶段和人工输入时间分开。复购只在满 30 天观察窗的首购工作区中统计另一新项目付款；$12 同项目追加不能当订阅证据。退款同时按订单数、金额和原因报。

作品指标包括可用候选率、局部改稿接受率、未改区域回归失败、每作品修复次数、模型/CPU 费用、事实检查覆盖、正常速度听审和愿意发布。按人群、渠道、设备、复杂度及创作方式分组；小样本给人数和个案，不只给百分比。

## 4 实验和成本边界

自助实验：两组各 10 个有真实发布任务且知道 $39 价格的团队，使用自身素材；每组至少 3 个独立非赠送付款并交付是方向性门槛，不是市场转化估计。代修标 assisted，先查输入/创意/修改阻力，不因一组失败直接否定人群。

GPT 实验：两用途页公开检索，内部问答只检查理解。陌生流量关联实际素材、候选、付款和交付；推荐不足继续直接招募，不承诺上线后固定天数来订单。

定价实验：先维持 $39/$12 与当前权益；只有有证据的问题才提出新价格实验，人群内随机分配避免混杂，活动 checkout 和已购权益不追溯改价。订阅依据新项目复购与更新频率，而非追加包次数。

成本覆盖支付成功/失败、税/退款/提现分摊、模型、素材、创作/预览/音频/QA、免费目标准备、全部套餐次数、3 个版本及多构图、存储交付和支持。用满套餐也要测，不只测一次编码。模型费用整数 USD micros，usage 未知保守预留并对账，不能因无限失败重试绕过预算。

运营起点 $20/天软提醒、$30/天暂停新免费操作是待标定内部策略，不是利润或供应商费率。已收款交付保留容量；agent-policy 的金额上限和价格版本未配置则 disabled。没有新商品不展示“购买预算继续”。按实际商户账单核费用，贡献不等于净利润。

## 5 推进条件

创意可用、自助改稿、付款和交付共同成立才扩大获客。定位漏斗失败环节，优先改善已有流程，不为关键词承诺未实现功能，也不以样片点赞推导转化。
