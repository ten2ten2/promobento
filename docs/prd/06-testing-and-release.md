# 测试与发布验收

本章对应 v2.5 / 协议 2.5.0，定义必须完成的验收范围。现有共享 JCS/Ajv、契约参考测试和 CI 只证明各自检查范围；真实渲染、数据库、支付与外部平台结果仍需实际验证，当前进度见[实施状态](../implementation-status.md)。认证、支付、语言/UI 按 12、05、10、02 验收。

## 1 素材与作品

测试素材覆盖：横屏软件截图/录屏/Logo/两卖点；竖屏 App/长名/重音；课程封面/目录/节选/报价/日期；无价格、评价、收益数据的数字产品。边界包括损坏编码、旋转、超大像素、不支持格式、超长旁白、CJK/RTL/组合字符/缺字、多个工作区和恶意提示。虚构品牌明确标注，素材有使用权。

两类用户、15/30 秒、四构图覆盖连续运镜、蒙太奇、混合及复杂 Canvas/WebGL；分类只为回归，不是创作白名单。同一素材至少制作两种镜头、构图或节奏明显不同的方案，并包含 Agent 自写的新镜头。静态图、空 JSON、固定六镜头演示均不能代替 M0 自由创作。

`packages/contracts` 是 JCS、摘要、身份函数与完整 Ajv 结构校验的唯一实现；根脚本负责读取配置和跨字段语义。输入从原始文本/字节经 `parseCanonicalJson` 解析，再校验与求摘要；已解析对象无法恢复被覆盖的重复键。`check:contracts` 和 `test:contracts` 检查示例与参考逻辑，子帧时间运算不证明真实像素合成，WAV 元数据断言不证明实际解码、混音或试听。

`check:repo` 检查当前文档、链接、配置、路由、认证、主题和契约。CI 对 `main` 推送及 PR 使用固定 mise 工具链、冻结 lockfile 和只读仓库权限执行检查，无部署步骤。是否通过以对应提交的实际结果为准。

## 3 QA、冻结与完整输出

Q0 源码和 Q1 实际帧以及必要内部片段、事实覆盖是可冻结来源的门禁；`releaseEligible` 不是完整视频已交付。Q2 对正式编码后的完整文件逐帧检查，全部满足后才发布。Q3 美学由用户和运营样本复核，不强制每单未预算人工审批。

BLOCK 不可豁免；REVIEW 精确绑定 rule/revision/target/帧区间和有效权限，变更后失效；INFO 不阻断。节奏密度、3 秒钩子、能量峰和调色雷同只提供诊断/REVIEW，不作为风格硬阻断；缺字、缺许可、错误事实、非法时长或不复现才进入对应 BLOCK。计划内静止/硬切不能一律报错，不凭风格分数担保安全、版权或商业真实性。不可检查的内容不记为 pass。

按 03 与冻结平台配置逐文件运行 ffprobe，验证编码、尺寸、帧数/时长、音轨、体积、旋转及音画误差。实际像素无意外黑尾/闪帧，音轨无意外静音/削波，关键字和焦点在安全区。颜色修改不无故改变音轨，节奏修改重新对齐。

Q0/Q1 报告检查完整输入及获准策略，Q2 检查实际完整产物；不能相互顶替。音频源越界、混音 WAV 字节或采样长度不符、预览/导出临时重混均须失败；冻结静音作品不伪造空音轨。子帧资源屏障、线性光合成及冷/顺/逆序像素一致性须在实际 Renderer 验证，画面采样不得推进音频事件。输入、声音与产物身份的字段规则唯一见 14。

适用的 AI 标记、受众披露及其实际文件证据验收按 09/14 执行；metadata 或映射文件存在不代表视频/封面已合规。采用 C2PA 等方案时，验证签名/完整性、检测与目标平台实际处理后的限制，缺覆盖不得记 pass。

首次目标集合的 video/cover/mapping 全部 ready 后原子发布/消费，单文件 ready 不下载。ZIP 和补目标不改变首次消费。停止 consumer/容器/dispatcher 后 outbox 和 lease 恢复，渲染最多 3 次实际尝试。部署新版后，已冻结作品仍能使用其规则与镜像重试/补目标；D1/R2 引用恢复和队列重放至少一次预发布演练。

## 4 支付、性能与平台门槛

执行 05 全部交易边界，特别是不同 snapshot 但相同 contentHash 不重复消费、退款与首次发布竞争、素材清理后迟到付款，以及下表。不能把内存参考状态机、mock、test模式或模拟交易写成真实D1/Waffo集成或实收。

| ID | 交易验收 |
| --- | --- |
| BILLING-01 | 四SKU价格/增量由服务端目录推导；single_export只允许purchase_and_export；其他商品top_up_only禁止snapshotId、不自动导出，purchase_and_export必须有效全目标snapshot |
| BILLING-02 | single_export/project_pack共享项目初始槽；不同SKU、不同snapshot或两个成员不能并发留下两个可支付初始订单；未知状态不释放槽，迟到入账进入对账/退款 |
| BILLING-03 | upgradeFromOrderId升级必填且绑定有效同项目单片，其他SKU禁止；只增2版本/5整片/15轮，不重置已用账；extra_pack仅完整项目权益可买 |
| BILLING-04 | 退款/新购不重置旧付款去重；依赖按追加→升级→初始退款，失败/未知阻止父退款；全链全额结清才释放有效槽，新购买必须新订单/新付款，原消费记录保留 |
| BILLING-05 | 7天未用退款同时检查发布、整片、改稿及素材处理；有任一实际消费不能按未用退款；技术交付失败、重复收费仍走相应退款保障，不与未用判断混淆 |
| BILLING-06 | 已发布且关联交付权益确被撤销时，同contentHash重新购买并导出在建checkout前转人工恢复，不自动复用旧收据/下载；未用追加额度退款、补偿或部分退款不得连带撤销其他有效输出，云交付变化不自动回转版权 |
| BILLING-07 | 7日自愿未用政策、Waffo工单窗口及不可排除的法定救济分别判断；已交付异常退款明确具体输出及许可处理，拒付调查与最终结论分开 |

方向、首关键帧、完整主目标预览、全部目标准备、局部 patch、编码、排队和交付分别记录 p50/p95、失败、模型/CPU 成本；未标定目标为 null。核对费用账本的operation/attempt/目标/模型/价格版本、共享费用分摊和多目标物理文件去重，免费队列包含未完成与未付款者。30天贡献同时报告未用付费权益的预计后续成本；模型算例按07复算，不能把生成样片后的转化率当作所有开始产生成本试用的转化率。

待测工程目标：普通参数更新 p95 ≤300 ms；LCP p75 ≤2.5 s；空队列单 30 秒构图编码 p95 ≤5 分钟、常用三构图批次 ≤12 分钟；支付 inbox 响应 10 秒、权益推进 60 秒。硬资源超时不是 SLA。完成率目标 95% 须报告样本及人工介入，少量自测不作为市场表现。

M0a 按 [08](08-codex-execution.md) 验真实自由作品、声音、无声可读、独立盲审及含免费流量/七目标准备/内部修复/失败重试的单位经济；没有实测数不得启用模型预算。M0b 验真实 Cloudflare 30 秒复杂源包、字体码位覆盖/合法回退、H.264 能力探测/FFmpeg PTS 抽帧、冷/顺/逆向 seek、WebGL、1/4/8 子帧性能对照、编码、禁公网、密钥隔离、销毁重建与跨任务残留。无账号时明确 NOT_TESTED，可继续无生产数据研究，不能开放客户代码。容量起点 10 串行及 4 混合并发，全部计算类别共同受 4 容器上限。

## 5 发布与证据

M4 需要真实 Google/邮箱送达和会话、Waffo 收款退款与超窗救济路径、品牌域名/DNS/TLS、支持渠道、安全回滚，以及六平台实际上传。经营/销售主体、实际市场与客户身份、条款/隐私、适用处理协议、素材许可和 AI 标记/披露按04/05/09完成；缺合同或实际能力不标记通过。审核/账号/编码失败分别归因，没测试账号可继续格式验收，但只称推荐规格。

网站政策按[内容发布规则](../../content/pages/README.md#5-发布与版本记录)核对变量、编辑提示、版本、锚点及接受记录；草稿或缺失事实的正文不得作为正式政策上线。正文入库和仓库检查不等于页面渲染、发布门禁或实际业务承诺已验证。

英语静态页面、无空语言 URI、主题 SSR/缓存隔离、404/405/410 和敏感日志按 10/12。发布开关包括注册、免费 AI、新 checkout、新创作/编码；停新成本仍保留查询、退款、既有下载和已付任务恢复容量。

### 证据保存

普通语法、文档链接、JSON 和参考测试结果写提交说明或 CI，不为每次修改创建日记。真实 Cloudflare 隔离/回收、正常速度视听、模型/成本基准、邮件送达、收款退款和平台上传等难复现、仍支持当前能力声明的结果，才在 `docs/evidence/` 建独立报告。

报告记录 commit、环境、实际命令、镜像/资源/模型版本、输入/输出 hash、目标/时长/runId、检查范围、ffprobe/帧/音频/费用及失败复现，明确失败和未运行项。占位、mock 和本地参考不标生产通过；短期 URL、验证码、密钥、客户源码/素材全文不进入公开日志。私有原始证据使用受控引用，保留和删除按 04。

报告失效且不再支持现行声明时移除引用与文件；仍需的许可来源、用户版本和订单/退款审计按各自目的保留。项目进度仅见[实施进度](../implementation-status.md)，不在其他入口复制完成清单。
