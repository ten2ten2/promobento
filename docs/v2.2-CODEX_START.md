# Codex 任务入口 — PromoBento v2.2

> 搭配 `docs/prd/13-agent-native-production.md` 使用。此文件是**任务指令**，不代表代码或部署已完成。

## 任务目标

依据仓库当前业务 PRD v1.4 和新第 13 章，将规划和后续实际工程升级为 v2.2 Agent-Native 视频生成产品：**对齐 huashu-motion 的导演方法、自由动画编码、程序化作曲、音效、逐帧 QA、指哪改哪与版本恢复**，同时保留 PromoBento 的 SaaS 业务边界。

**产品硬约束：**

- 视频时长仅 `15|30` 秒，默认 30 秒，30fps（450/900 帧）。
- 比例/分辨率/编码仅来自既有的六个平台预设（包括预设内可选的方形）。
- 不限制 Agent 的场景数、动画实现、镜头语言、风格、自定义代码与构图；模板和 20 种运动语言是参考，不是上限。
- 真实素材/商业事实必须经用户确认；安全、授权、预算和多租户隔离不可绕过。

1. **盘点而不是覆盖**：阅读现有 `AGENTS.md`、根目录、当前 PRD 01–14，尤其14的正式契约与主状态机；列出现有实现、缺口与测试。不要删除原代码、覆盖现有 `AGENTS.md` 或猜测用户已有环境。
2. **锁定上游**：检出/浏览 `alchaincyf/huashu-motion@5f2608c2e12abcf518f74dde86093b19f7f88603`；逐项检查 `director/rhythm/library/sound/check/qa/studio/inbox/learn/runtime`，创建 `docs/UPSTREAM_ADOPTION.md`，明确每项为 `PORT | ADAPT | REBUILD`，含 License、测试和来源 commit。GSAP 不直接默认打包，作者角色与未经审核媒体/采样不复制。
3. **修订主文档**：根据 v2.2 第 14 节修改当前 PRD 的相应章节，只覆盖冲突条目。保持 Waffo、已有计费合同、登录（Google+邮箱）、React/Cloudflare/mise、团队权限、网站英语首发、用户文案自由混排、Light/Dark、平台导出、数据保留与删除策略。
4. **M0 真实视频闭环**：Director → Treatment（节奏单+关键帧）→ 自由源码 Composition → Agent 编写自定义运镜 → 浏览器 seek → 真实帧图 → ABC 作曲/音效 → FFmpeg → MP4 → `check/qa` 证据。M0a至少测试15/30秒、两类素材和原创镜头；M0b在真实Cloudflare证明复杂片/字体/seek/WebGL/编码/销毁隔离，缺少此结果不可宣称M0云端通过。
5. **M1 Studio 编辑闭环**：实时预览 + 时间帧/坐标点选 + DOM/Canvas/WebGL 目标定位或截图兜底 + Agent scoped patch + before/after 验证 + revision history/revert + 普通变量本地编辑。
6. **M2 生产沙箱与可靠性**：Composer 与 Renderer 均视为不可信执行边界；隔离容器/任务、禁公网、隔离预览 origin、最小授权资产代理、版本锁、镜像/依赖锁、R2 快照、作业 lease/幂等/预算与故障恢复。Cloudflare Sandbox SDK 具体稳定/预览版本在实施时按官方文档和实际压测决定。
7. **M3团队运营与M4生产门槛**：复用/完成账户、工作区、Waffo、支付权益、多平台预设导出、上传权限、退款、监控、数据清理；将创作成功次数、系统预算与成片权益分离；所有target源包在付款前冻结，补平台不得重调Agent；M4完成真实生产验收。

## 必须交付的证据

按 `docs/evidence/README.md` 仅为关键验收列出用例的 Git commit、环境、容器 digest、模型配置、真实运行命令、资产 hash、输出 MP4/JPG、ffprobe 结果、QA 报告、成本与失败复现。证据路径缺失则标 `NOT_TESTED`；不可填假造通过数据。

**最关键的 M0/M1 反例测试：**

- 同一截图生成两条不同镜头语言的片子，不能只换背景色。
- “镜头绕 UI 环绕 180° 再穿屏”由 Agent 写**此前不存在的动画代码**实现；15 秒或 30 秒都严格满足目标帧数。
- 每条有实际配乐/音效或用户明确选择静音；检查节拍和最终文件，不能拿音轨 JSON 当已生成声音。
- `om check` / `om qa` 对应的源码检查、闪帧、静止空档、硬切、布局与历史依赖检查能对真实缺陷给出帧号与截图；计划内静止不误封。
- 点击 Canvas 或 WebGL 的任意位置后能提供时间+截图兜底让 Agent 修改，无法读 DOM 不构成编辑失败。
- 同一修改失败、模型超预算、队列重复投递、用户撤回时，原 revision 和已付费额度保持一致。
- 非法 45 秒、自定义任意画幅/宽高、跨租户资源引用必须由**服务端**拒绝。
