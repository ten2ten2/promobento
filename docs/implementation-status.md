# 当前实施状态

当前为 PRD **v2.5**、协议 **2.5.0**。已有 13 篇主题规格、配置和离线 Studio 设计，以及以下可执行工程基础：

- `packages/contracts` 提供 JCS 规范化、原始 JSON 解析、内容/产物身份及完整 Ajv Draft 2020-12 校验。
- 契约参考覆盖子帧采样时间、Q0/Q1 输入绑定、Q2 输出证据、冻结事件与实际混音 WAV 身份，以及试用、计费、授权和状态边界；这些检查不渲染或试听媒体。
- `.github/workflows/checks.yml` 在 `main` 推送和 PR 上使用固定 mise 工具链执行检查；实际运行结果以对应提交的 CI 为准。

另有 [Terms、Privacy、Refund 英文内容草稿](../content/pages/README.md)及构建上下文示例。正式主体、供应商和部分保留事实未齐，页面渲染器、模板与发布校验尚未实现；正文入库不代表政策已对外生效。

创作运行时和桥接 API 已有类型合同。**生产 Agent、真实渲染、数据库、认证、支付及隔离服务仍未实现。** 真实作品、全部成本和付费转化尚未测得。
