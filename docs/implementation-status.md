# 当前实施状态

本仓库已有现行 PRD v2.4 的 13 篇主题文档、配置、2.4.0 JSON Schema/RenderProtocol、关联示例、语义/状态参考测试、仓库检查及离线Studio参考。**这些不是实际产品服务。**

当前规格覆盖一次账号试用、单片购买/项目包/差额升级/追加、试用耗尽后的先购创作、付款导出意图、全目标冻结、按操作归因及首购贡献模型。本轮补充了成片许可/退款边界、素材与事实证据、隐私、AI 标记及披露要求；参考校验不代表已经建成权利审核、删除或标记服务。真实样片成本、付费转化与报价表现尚未测得。
