下一阶段是 **M0a 第三步之前的 Agent 源码执行准入**，再接软件/课程两个真实创作题目，实施顺序和退出条件见 [08 实施与交付](prd/08-codex-execution.md)。当前媒体样片是自制虚构界面和程序音轨，字体范围为固定Latin子集；工程检查不代表自由创作、复杂文字塑形、正常速度人工试听或全部M0a通过。模型、价格和费用上限尚未用真实任务标定，Agent保持`enabled=false`；模型作品、成本和付费转化尚未测得。

`render:fixture`默认运行`media`的output模式，记录出片、媒体与必需抽查；完整`test:render`另含全帧倒序、编辑/故障回归。报告分开准备、捕获编码、检查及清理时间，单次耗时不代表生产p95。本地半分辨率与高清帧的边缘可有重采样差异，同分辨率重放才要求完整像素hash相同。当前`chromiumSandbox:false`不可用于Agent/客户源码，首次执行前须通过[08的准入条件](prd/08-codex-execution.md#agent源码执行准入待实现)。结果以精确提交和CI运行/attempt及其报告、样片、环境为准；未取得结果不标通过。长期验收证据按[06](prd/06-testing-and-release.md#5-发布与证据)管理。
